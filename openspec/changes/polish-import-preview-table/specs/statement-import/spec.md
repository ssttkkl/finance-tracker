## ADDED Requirements

### Requirement: 导入预览正确表达月份行、处理状态和零金额

导入预览 MUST 让月份分组行覆盖表格全部列；待新增、已存在、暂不支持和无法识别状态 MUST 使用清晰可辨的中文标签；精确为零的金额 MUST 不带正负号、方向色或方向箭头，并使用默认文字颜色。

#### Scenario: 月份分组行覆盖完整表格

- **WHEN** 导入预览按月份展示流水
- **THEN** 每个月份分组行 MUST 横向覆盖当前表格的全部列，包括金额列

#### Scenario: 状态标签具有明确视觉层级

- **WHEN** 预览行状态为待新增或已存在
- **THEN** 页面 MUST 显示中文状态标签，且标签的文字、背景和边框具有足够对比度以区别于普通表格文字

#### Scenario: 零金额不表达收入或支出方向

- **WHEN** 预览或收支账本流水的金额为 `0`、`0.00`、`-0.00` 或等价的零值十进制文本
- **THEN** 金额 MUST 显示为无符号值和币种
- **AND** 金额 MUST 使用默认文字颜色，且不得显示收入 / 支出方向箭头

#### Scenario: 点击摘要筛选预览流水

- **WHEN** 使用者点击“全部”“待新增”“已存在”或“无法识别”摘要块
- **THEN** 下方预览表格 MUST 只显示对应处理状态的流水；“无法识别” MUST 对应现有无法识别数量
- **AND** 被选中的摘要块 MUST 保持可感知的选中状态并支持键盘操作
- **AND** 点击“全部” MUST 恢复所有预览流水，筛选不得改变导入确认请求

#### Scenario: 摘要筛选没有匹配流水

- **WHEN** 使用者选择数量为零的状态摘要
- **THEN** 页面 MUST 显示可读的无匹配提示，且不得显示空的流水行
