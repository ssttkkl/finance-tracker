## Why

已登录主界面的工作区切换和退出操作占用顶栏空间，宽屏侧栏又固定展开且使用不同于入口页的深色大面积背景。统一为可收起的图标导航，并将身份和工作区操作集中到侧栏底部的头像菜单，可让页面标题与内容获得更稳定的空间，同时保留现有页面入口和工作区操作。

## What Changes

- 六个现有目的地继续作为同级导航入口，不再按业务类别嵌套分组；`REGULAR` 与 `WIDE` 默认展示可展开的图标侧栏，`COMPACT` 继续使用抽屉。
- 在支持鼠标悬停的桌面设备上，指针进入侧栏任意区域时自动展开，离开侧栏与账号面板后自动收起；悬停头像自动打开账号面板。点击展开按钮可固定/取消固定侧栏，触屏仍使用点击控制。
- 移除侧栏顶部的圆形 `F` 品牌标识；桌面侧栏顶端只保留独立的展开/收起按钮，手机抽屉仅保留文字标题。
- 将头像入口移至侧栏底部。头像以邮箱首字母生成；点击后展示邮箱、可访问工作区与角色、工作区管理入口和退出登录。
- 从顶栏移除工作区切换与退出操作；保留当前页面标题及适用的返回操作。
- 明确宽屏、常规窗口和窄屏上的导航、焦点、选中态、菜单关闭与工作区切换行为；不改变现有认证和工作区服务语义。

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `shared/cross-platform-presentation`: 更新已登录 Compose 主界面的一级导航、响应式侧栏及头像账号菜单合同。

## Impact

- 影响 Compose `commonMain` 应用壳、导航数据、共享语义标识和相关 Web/Android/iOS 界面验证；`docs/feature-map.md` 同步更新。
- 不改变认证/工作区 API、路由、成员权限、账本数据或持久化，也不新增个人资料编辑或头像上传能力。
- Legacy React Web 与 Expo 不在范围内；无需数据库迁移或依赖变更。
- 可通过回滚本变更的 Compose presentation、规格和地图更新恢复旧导航位置。
