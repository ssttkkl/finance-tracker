## Purpose

定义使用者在只读 Web 中浏览投资事件、核对来源与关系证据，并查看当前持仓及估值状态时的完整行为。

## ADDED Requirements

### Requirement: 投资事件列表支持稳定筛选和分页
系统 MUST 为当前工作区返回投资事件的发生时间、账户、记录类型、记录子类型、标的、付出资产、换入资产、手续费、来源说明和导入渠道。列表必须支持浏览器本地日期范围、投资账户、记录类型和标的筛选，并使用绑定排序键、筛选条件和数据版本的稳定分页游标。

#### Scenario: 按账户和标的连续翻页
- **WHEN** 使用者选择一个投资账户和标的，并在数据版本不变时连续翻页
- **THEN** 列表 MUST 按稳定顺序返回全部匹配事件，不重复或遗漏同一排序范围内的事件

#### Scenario: 数据变化后使用旧游标
- **WHEN** 新投资事件使列表数据版本变化后，使用者继续提交旧游标
- **THEN** API MUST 返回可识别的游标失效错误，且不得把两个版本的数据混入同一分页序列

### Requirement: 当前页批量提供关系摘要和受控证据
系统 MUST 按当前页投资事件批量读取关系摘要，避免逐行查询。证据详情必须限定当前工作区，展示正式字段、来源行快照中的可核对业务信息和已确认关系影响；不得暴露内部代理键、凭据、完整认证材料或其他工作区数据。

#### Scenario: 查看现金—投资资金调拨证据
- **WHEN** 使用者打开一个具有已确认资金调拨关系的投资事件详情
- **THEN** 详情 MUST 展示投资端与现金端账户、精确金额、币种、方向和关系影响，并隐藏不属于业务证据的内部字段

#### Scenario: 跨工作区读取证据
- **WHEN** 请求使用当前工作区之外的投资事件标识读取详情
- **THEN** API MUST 拒绝访问，且不得泄露目标事件是否存在

### Requirement: 投资事件与当前持仓明确分区
Web MUST 把“投资事件”和“当前持仓”作为语义不同的只读区域。持仓区域必须复用既有组合查询，展示账户、标的、数量、成本、当前单价、计价币种市值、展示币种折算市值、估值状态和原因；不可用金额必须为空，不得显示为假 `0`。

#### Scenario: 查看持仓和历史事件
- **WHEN** 一个标的同时具有当前非零持仓和历史投资事件
- **THEN** 页面 MUST 分别展示当前持仓状态与有序事件，且不得把持仓快照伪装成交易事件

### Requirement: 行情局部失败不阻塞投资事件浏览
系统 MUST 在共享有界预算内批量查询当前持仓估值。一个行情或汇率数据源超时、返回部分结果或不支持标的时，受影响持仓必须保留 `stale`、`partial` 或 `unsupported` 状态及原因；其他持仓和全部投资事件必须继续可浏览。

#### Scenario: 一个行情数据源超时
- **WHEN** 一个数据源在总预算内未返回而其他数据源成功
- **THEN** 仅相关持仓 MUST 显示受限状态，其他持仓与投资事件列表必须保持可用

### Requirement: 金额和时间保持无歧义
API MUST 以十进制字符串返回投资金额、数量、成本、单价和市值，并为发生时间返回带明确 offset 的值。Web 必须按浏览器本地时区展示时间和解释日期筛选，不得用二进制浮点重新计算账务数值。

#### Scenario: 展示高精度投资事件
- **WHEN** 投资事件包含超过常见货币两位小数的合法数量和成本
- **THEN** API 与页面 MUST 保留原十进制精度，且筛选和排序不得改变该值

### Requirement: 投资账本 Web 支持键盘和响应式布局
筛选、列表、分页、区域切换和证据详情 MUST 可通过键盘操作，具有正确语义和可见焦点。证据抽屉或模态层打开时背景不可交互，关闭后焦点必须回到原入口；在 320、375、414 和 768 px 宽度不得出现页面级横向滚动或关键信息溢出。

#### Scenario: 键盘核对事件证据
- **WHEN** 使用者通过键盘打开并关闭一条投资事件的证据详情
- **THEN** 焦点、背景交互和关闭行为 MUST 符合模态语义，且完整业务信息仍可访问

### Requirement: 双后端返回等价的投资浏览合同
PostgreSQL 与 SQLite MUST 对相同工作区、投资事件、关系、持仓、行情和汇率输入返回等价的列表、分页、证据和估值状态。工作区隔离、精确十进制和错误结果不得因数据库后端不同而改变。

#### Scenario: 比较双后端投资浏览响应
- **WHEN** 两个后端使用相同去标识化夹具执行列表、详情和持仓查询
- **THEN** 除内部代理键外，响应内容、顺序、精度、状态和错误合同 MUST 等价
