## ADDED Requirements

### Requirement: 工作区管理作为一级页面提供管理任务

系统 MUST 在统一侧边导航中提供与收支账本、投资账本同级的“工作区管理”入口。页面标题 MUST 为“工作区管理”，不得使用当前工作区名称替代页面标题，也不得提供重复的页面内账本返回入口。

#### Scenario: 成员从侧边导航打开工作区管理

- **WHEN** 已登录成员点击“工作区管理”
- **THEN** 系统 MUST 在统一右侧内容区打开工作区管理页面，并且侧边导航只标记该一级入口为当前项

#### Scenario: 页面不重复提供账本导航

- **WHEN** 工作区管理页面加载完成
- **THEN** 页面 MUST 不显示“返回账本”链接或常驻功能介绍、操作影响说明

### Requirement: 工作区身份信息区分固定 ID 与可编辑名称

工作区管理页面 MUST 将页面标题与工作区名称分开呈现。管理员 MUST 能编辑工作区名称；固定工作区 ID MUST 只读展示并支持复制，名称修改不得改变固定 ID。

#### Scenario: 管理员修改工作区名称

- **WHEN** 管理员修改名称并点击“保存”
- **THEN** 系统 MUST 保存新名称、保留原固定 ID，并在页面上反馈保存结果

#### Scenario: 成员复制固定工作区 ID

- **WHEN** 成员点击固定 ID 旁的“复制”
- **THEN** 系统 MUST 将当前工作区固定 ID复制到剪贴板或提供可复制的选中值，并反馈复制结果

### Requirement: 成员与邀请按管理任务横向组织

工作区管理页面 MUST 在同一宽内容区展示成员和邀请任务。管理员 MUST 能调整其他成员角色、移除成员并创建指定角色的邀请链接；非管理员 MUST 只能查看成员和当前工作区信息，不能执行这些写操作。

#### Scenario: 管理员管理成员和创建邀请

- **WHEN** 管理员在页面调整成员角色、移除成员或选择“可编辑/仅可查看”后点击“创建链接”
- **THEN** 系统 MUST 调用既有成员/邀请行为并在页面显示对应结果，邀请角色以创建时选择为准

#### Scenario: 非管理员访问工作区管理页面

- **WHEN** `editor` 或 `viewer` 打开工作区管理页面
- **THEN** 页面 MUST 保留工作区、成员和邀请的信息结构，但名称、角色、移除和创建邀请控件 MUST 不可写入

### Requirement: 工作区管理页面适配桌面与移动视口

页面 MUST 在桌面端填满统一账本壳的右侧滚动区，并在移动端改为单列布局；在 320、375、390、414、768 和 1440 px 宽度下 MUST 不产生横向滚动或文本溢出。

#### Scenario: 桌面端使用可用内容宽度

- **WHEN** 使用 1440 px 宽度打开工作区管理页面
- **THEN** 成员区域和邀请区域 MUST 横向排列并使用右侧可用宽度，右侧内容区可独立滚动

#### Scenario: 移动端使用单列布局

- **WHEN** 使用 390 px 宽度打开工作区管理页面
- **THEN** 工作区身份、成员和邀请区域 MUST 按单列排列，页面 MUST 无横向滚动且所有主要操作可触达
