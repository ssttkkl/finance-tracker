## Why

用户和 AI 需要在终端里查看账本、记账和完成现金账单导入。现有客户端已定义收支汇总、导入核对、离线访问和实际保存结果，同一业务操作应在终端得到相同结果。

## What Changes

- 提供通过 npm 安装的 Kotlin/JS（Node.js）命令行程序 `ft`，支持终端文本、可编程 JSON 输出和无交互操作。
- 首期覆盖登录与注册、工作区与成员邀请管理、记账和导入实际使用的账户操作、收支浏览与维护、收支分类，以及完整现金账单导入。
- 每次执行独立判断当前操作能否访问后端。保留加密快照和导入批次，支持断网重启后的本地浏览与准备，正式写入仍须在线。
- 对带预期工作区的管理写入提供与服务端会话选择一致的事务保护。

一期之外的能力包括投资账单导入、投资流水和持仓、独立账户编辑与删除、余额校准、后台联网监听和联网自动提交。

验收以同一组夹具和相同用户选择比对 Compose 与 CLI 的列表、汇总、来源、导入结果及实际余额。首个贯通场景为联网同步工作区、退出进程、断网启动新进程查看同一笔收支、账单来源和上次同步时间。

## Capabilities

### New Capabilities

- `shared/ledger-cli` 定义命令行入口、输出、跨进程恢复以及一期任务覆盖。

### Modified Capabilities

- `workspace/workspace-management` 新增管理写入的预期工作区守卫。

## Impact

A 类变更。涉及 Compose 与 CLI 共享客户端逻辑、桌面端本机安全存储、可执行程序分发，以及 JVM 后端的工作区保护。账本继续通过现有 API 访问 SQLite 或 PostgreSQL。新守卫兼容现有调用方；CLI 版本可单独撤回，已取得的收据、未决操作和加密批次按原范围恢复。
