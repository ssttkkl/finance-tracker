## 目标与布局结构

- 信息结构保持不变：顶部筛选卡片，下方可滚动的按月流水列表；`REGULAR` / `WIDE` 月份汇总和列标题随月份固定显示。
- `REGULAR` / `WIDE` 的月份表格容器及吸顶月份栏右边缘与筛选卡片右边缘对齐。
- 移除的冗余空间：列表视口和吸顶月份栏外侧多出的 16 dp 右缩进。
- 表格行内容仍在月份容器内左右缩进 16 dp，分隔线继续横跨月份容器。

## 实现选择

`CashLedgerScreen.kt` 的 `LazyColumn` 当前在非 `COMPACT` 尺寸追加 `padding(end = 16.dp)`，月度吸顶 `Surface` 也追加相同缩进。删除这两处外层缩进，使两个表面延伸至与筛选卡相同的右边界。保留行内容自身的 16 dp 内缩，因此表格列、金额与行内操作不会贴到外框；竖向滚动条仍叠加在列表上，40 dp 交互热区不参与布局测量。

列表和吸顶月份栏共用这一对齐边界，避免滚动前后表格外框跳变。`COMPACT` 已没有这两处非紧凑尺寸缩进，继续维持现状。

## 跨平台影响

- Web：Compose Web 在 `REGULAR` / `WIDE` 中的月度表格和吸顶栏右边缘与筛选卡对齐。
- Native：Android/iOS 在 `REGULAR` / `WIDE` 中消费同一共享布局，获得相同边界；`COMPACT` 无变化。
- Shared：仅调整 `CashLedgerScreen.kt` 中两个外层布局缩进；不改变语义 ID、页面区域顺序、行内容间距或滚动行为。

## 风险与回滚

移除列表缩进后，滚动条绘制在月份容器范围内。行内容右侧仍缩进 16 dp，给窄轨道留出视觉间隔；40 dp 热区继续覆盖列表。若运行时发现轨道遮挡行内操作，可单独修正轨道位置并回写本变更，不通过重新收窄月份容器来处理。

回滚只需恢复 `LazyColumn` 和吸顶 `Surface` 的非 `COMPACT` `padding(end = 16.dp)`，无需数据迁移或服务端变更。
