## MODIFIED Requirements

### Requirement: 临时导入会话保存来源但不写入业务账本

系统 MUST 在每次上传请求内解析文件并删除原始输入，不将原文件或密码保存至会话；只保存有 TTL 的解析行、必要来源范围和选择。一个会话最多 20 份文件，每份最多 100 MB。预览 MUST 不写流水、来源绑定、映射或关系；账户普通命令独立立即生效。

#### Scenario: 首次上传及删除输入

- **WHEN** 上传受支持账单
- **THEN** 返回绑定操作者和工作区的不透明会话及逐文件结果；再次预览只读解析结果，原文件不能下载或重读

#### Scenario: 独立账户生效

- **WHEN** 在导入内创建或修改账户成功
- **THEN** 该账户立即可查询和选择，退出导入不自动撤销

### Requirement: 会话必须绑定工作区并在期限后失效

会话、不可变计划和临时重试内容 MUST 绑定操作者和工作区且有限期；每次文件或选择改变 MUST 比较修订并使旧计划失效。读取不得隐式无限续期，过期返回安全可识别错误；已经提交的收据不随会话过期。

#### Scenario: 跨工作区访问

- **WHEN** 另一工作区或操作者使用会话标识
- **THEN** 拒绝且不泄漏内容

#### Scenario: 两个请求重预览

- **WHEN** 两个请求使用相同会话修订
- **THEN** 最多一个发布成功，提交只接受当前最新计划

### Requirement: 关系决定只在最终确认时提交

关系决定 MUST 在统一预计流水列表中按需维护，流水、映射及关系只有一次最终提交。未确认关系默认作为草稿保存；强建议拟确认也不得提前写入。

#### Scenario: 暂不处理关联

- **WHEN** 两条正式流水的关联未确认并点击确认导入
- **THEN** 两笔正式流水及草稿关联一起保存，两项分别展示并统计

### Requirement: 最终确认必须幂等且可安全重试

最终确认 MUST 消费服务端不可变计划，按操作者、工作区、幂等键和唯一上下文防重复消费；流水、关系组、投影及逐项收据 MUST 同一外层事务发布。单项业务失败不阻止其他项，无法恢复的全局事务失败整体回滚。

#### Scenario: 响应丢失后重试

- **WHEN** 相同计划与幂等键再次提交
- **THEN** 返回原收据，不重跑成功项或失败项，即使临时会话已清理

#### Scenario: 不同键重复消费

- **WHEN** 已成功消费会话再次使用另一个键
- **THEN** 不写入并返回有权访问的收据引用

#### Scenario: 单项失败

- **WHEN** 一条流水或一组关联无法保存且保存点可恢复
- **THEN** 该项回滚，其他独立项继续，收据说明实际结果

### Requirement: 临时来源遵守隐私和清理边界

解析内容 MUST 仅由受控服务存储，来源正文、密码、令牌和路径不得进入日志；成功项解析正文及时清理，可重试失败行最多保留到原 TTL。永久收据 MUST 不保存原账单正文或完整差异。生产临时存储未配置时失败关闭。

#### Scenario: 临时失败重试

- **WHEN** 部分完成后原 TTL 内重试失败行
- **THEN** 创建新会话及新计划，成功项不重跑，失败子集不冒充完整来源范围

#### Scenario: 过期重试

- **WHEN** 失败解析内容已到期
- **THEN** 要求重选文件，已保存草稿仍可从主页维护

### Requirement: 文件级扫描状态必须可重试且全部就绪后才能继续

文件 MUST 分别返回就绪、部分可用、需密码或失败；可处理文件及可辨认业务行 MUST 不被其他文件问题阻塞。重试需原文件及当次密码，删除或替换文件只改变对应临时解析内容。全部无业务行时只显示文件结果。

#### Scenario: 某文件无法解析

- **WHEN** 一份文件失败而其他文件有可辨认行
- **THEN** 允许预览并导入其余记录，显示失败原因且不伪造整文件草稿

#### Scenario: 单行解析异常

- **WHEN** 可定位的一行解析失败
- **THEN** 该行跳过并返回安全原因，继续处理其他行

## ADDED Requirements

### Requirement: 提交结果未知可以权威终结

系统 MUST 提供按键收据查询和提交状态核实。未查到收据不代表未提交；核实与提交使用同一工作区同步边界，只有确认计划永久不可执行且无收据才返回未提交。

#### Scenario: 过期计划且无收据

- **WHEN** 在途提交退出同步边界后计划已永久过期且没有收据
- **THEN** 返回未提交，允许重新导入；旧请求不得之后再执行
