## ADDED Requirements

### Requirement: 导入短暂操作反馈使用所属任务的 Snackbar

文件选择器打不开、请求中尝试退出及账户已就绪后选择账户的已识别临时读取失败 MUST 使用 Snackbar，不在页顶遗留同一错误或要求额外确认。超出总文件容量 MUST 补一次批次提示并保留未加入文件的原因和删除入口。取消选择文件不提示。消息 MUST 不因重复点击积压，问题解决只清理同一原因的提示，子表单内触发的提示在该表单可见。

#### Scenario: 上传过程中尝试退出

- **WHEN** 请求进行中按 Escape 或触发任务退出
- **THEN** 保留任务及请求，使用 Snackbar 提示等待；不打开需要点击确定的弹窗

#### Scenario: 选择账户的临时读取失败

- **WHEN** 账户列表已就绪，选择目标账户时发生已识别网络或临时服务读取故障
- **THEN** 保留原选择并显示一次带“重试”动作的 Snackbar，重试读取同一账户，仍允许重新选择；不采用旧缓存冒充成功
- **AND** 资格失效、首次加载失败、账户写入和提交结果未知仍保留对应持续状态

#### Scenario: 追加超过文件容量

- **WHEN** 新选择的一批文件有部分超出当前总容量
- **THEN** 汇总提示未加入的文件数量，已接受文件继续按原队列处理，超限项保留原因与移除入口

### Requirement: 导入任务异常保留诊断且不继续失败操作

共享客户端 MUST 区分预期业务／外部故障与内部错误；内部错误保留原异常和调用栈，在任务边界停止受影响操作并显示“系统错误”安全兜底。不得把代码错误转成单文件失败、普通分页重试或逐账户跳过后继续。已有独立成功结果及原写入恢复键 MUST 保留。

#### Scenario: 上传中的程序错误

- **WHEN** 文件读取、数据映射或恢复指针保存发生内部错误
- **THEN** 停止当前上传队列，不从完成回调重新启动；显示任务错误并保留诊断，不归因于文件格式

#### Scenario: 分页违反合同

- **WHEN** 服务端返回不符合当前计划／范围的分页
- **THEN** 停止采用该结果并报告合同错误，不拼接进已有列表或显示为可重试网络失败

#### Scenario: 已有内容刷新失败

- **WHEN** 已有可用内容的刷新因已识别外部故障失败
- **THEN** 保留内容和用户未提交的有效选择，提示本次刷新失败；首次依赖加载失败仍阻断主流程；明确网络或临时服务读取故障提供重试按钮，不可恢复的系统错误只显示“系统错误”并保留安全退出

### Requirement: 导入重试和账户操作保留原命令身份

确定未提交且允许原请求重试的导入 MUST 提供原请求重试入口，不因错误正文遮蔽该入口；结果未知 MUST 核实原请求。账户存在未决写入时，同一账户的修改与自动币种补齐 MUST 不创建新键；恢复信息无法判定目标时先核实该操作。

#### Scenario: 确定未提交时显示重试

- **WHEN** 已识别可恢复故障的提交状态允许重试原命令且已有错误文案
- **THEN** 同时显示错误与原请求重试，点击保留原命令及幂等键

#### Scenario: 币种补齐结果未知后再次下一步

- **WHEN** 账户币种更新已发出但结果未知，重新读取仍返回旧币种
- **THEN** 下一步不生成新更新命令或新键，提示先核实账户操作；已成功的独立账户修改保留

#### Scenario: 刷新不覆盖本次账户选择

- **WHEN** 用户在当前会话修改账户选择或暂不选择后刷新，来源分组仍有效
- **THEN** 保留当前未提交选择，不用旧预览或推荐账户替换，不建立跨导入的长期空选择策略
