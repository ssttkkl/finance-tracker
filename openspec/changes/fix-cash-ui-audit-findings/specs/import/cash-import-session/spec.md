## ADDED Requirements

### Requirement: 导入步骤与账户分组只呈现一次当前步骤

导入任务 MUST 只用一个层级表达当前步骤名称，步骤条 MUST 区分已完成、当前和未开始。步骤条、内容列和底部操作 MUST 使用一致的水平对齐基准。账户分组标题 MUST 统一以来源账户或渠道为主标题，文件信息作为次级说明。

#### Scenario: 当前步骤名称

- **WHEN** 使用者进入账户准备步骤
- **THEN** 页面 MUST 不重复显示同一句步骤标题
- **AND** 步骤条 MUST 能识别已完成、当前和未开始步骤

#### Scenario: 对齐与分组

- **WHEN** 在桌面宽度查看导入准备步骤
- **THEN** 步骤条、内容列和底部操作 MUST 对齐到同一内容边界
- **AND** 各账户分组 MUST 使用一致的标题结构
