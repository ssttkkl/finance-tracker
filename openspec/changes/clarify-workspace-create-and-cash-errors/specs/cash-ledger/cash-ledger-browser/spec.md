## ADDED Requirements

### Requirement: 现金新建编辑草稿错误按字段呈现并可定位

现金新建、流水编辑和草稿编辑在保存或预览校验失败时，客户端 MUST 把可归属到具体输入的错误显示在该字段旁，并把视口滚动、焦点移到首个错误字段；MUST 保留其他已输入值。用户修改某个字段后 MUST 只清除该字段的错误，其他字段错误继续保留。无法归属到字段的网络、权限或服务端错误 MUST 继续以表单级错误呈现。字段错误 MUST 可被读屏识别，不得只靠红色边框表达。

#### Scenario: 金额无效

- **WHEN** 用户提交的金额格式非法或超出允许范围
- **THEN** 金额字段旁 MUST 显示具体原因，焦点/滚动 MUST 定位到金额字段，其他已填字段保持不变

#### Scenario: 多个字段错误按首错逐次修正

- **WHEN** 一次提交同时存在金额、币种和账户等非法输入
- **THEN** 客户端 MUST 按字段顺序显示并聚焦/滚动到首个可归属错误，不得只显示无字段的表单级提示
- **AND** 用户修正并再次提交后，MUST 继续呈现下一个错误，直到全部通过

#### Scenario: 修改其他字段不误清错误

- **WHEN** 当前某个字段有错误，用户修改的是另一个字段
- **THEN** 原字段错误 MUST 保留，直到对应字段被修正或重新提交
- **AND** 修正当前错误字段后，该字段错误 MUST 被清除

#### Scenario: 无法归属的服务端错误

- **WHEN** 保存失败是网络中断、权限不足或服务端内部错误，无法对应到单个输入
- **THEN** 错误 MUST 以表单级状态显示，不得错误地标红某个字段或把焦点移到无关字段

#### Scenario: 草稿允许缺项但已填值非法

- **WHEN** 草稿允许留空，但用户已填写的资金字段互相矛盾或账户无效
- **THEN** 对应字段 MUST 显示错误并阻止保存，未填写的字段仍按草稿规则允许为空
