## ADDED Requirements

### Requirement: 工作区切换后立即重载收支账本

收支账本 MUST 将当前工作区 ID 作为页面读取上下文。工作区切换成功后，页面 MUST 立即重新读取列表、筛选选项和月份汇总，并且在新响应完成前不得继续展示旧工作区的账本记录；切换失败时 MUST 保留旧工作区页面和数据。

#### Scenario: 成功切换后不刷新浏览器即可显示新账本

- **WHEN** 使用者在收支账本页面把工作区 A 切换为工作区 B，且 B 有不同的现金流水
- **THEN** 页面 MUST 在不刷新浏览器的情况下显示 B 的列表和筛选结果，且不得残留 A 的记录

#### Scenario: 切换失败保留原工作区

- **WHEN** 工作区 B 的选择请求失败或 B 不再属于当前用户
- **THEN** 页面 MUST 继续显示工作区 A 的账本、URL 和工作区选择值，并展示可操作的切换错误
