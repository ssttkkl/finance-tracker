## 1. 思考与审查基线

- [x] 1.1 对照 [Material 3 Dialog 指南](https://m3.material.io/components/dialogs/guidelines) 与 Compose Material 3 实现文档，从视觉设计、业务行为两方面盘点共享 Compose 中标准对话框、自定义 Dialog、对话框式 Popup 的任务、动作、关闭路径、主题角色和响应式边界。重点：只有含暂存输入或未保存修改的 Compact 任务使用全屏；只读详情和短确认使用基础对话框；标题清楚、确认与取消最多各一项且确认靠逻辑末端；取消动作不可禁用；全屏任务可承载基础对话框，基础对话框用原容器内联状态表达次级确认；Escape 按顶层菜单到父任务的顺序处理；请求中确认仍可用、重复写入受拦截且失败可见。M3 指南页面经浏览器读取时返回 JavaScript 壳；同时对照 Compose 官方 Dialog 文档、M3 surface 角色指南和实际 `commonMain`/Web 截图。第二轮发现及处置见 4.1。

### 审查发现与处置

- `major`：Regular/Wide 流水编辑中的“放弃修改”状态把一行正文和操作行放进 `fillMaxSize` 的滚动正文，导致短任务仍占满基础对话框最大高度，且操作跟随正文而非固定操作区。将操作移至 `CashRecordModalPanel` 固定页脚，正文按内容收缩；同样将编辑、影响确认、删除、关联移除和创建关联的宽屏操作统一固定在页脚。待三尺寸截图与交互回归后复核。
- `major`：流水面板切换任务后，Compose Web 语义树仍暴露上一个任务的标题和控件。按 `sizeClass + title` 重建面板语义子树，并新增状态切换浏览器回归用例。
- `major`：Compact 导入请求中点关闭会在全屏任务上再叠一层信息 `AlertDialog`，与任务合同不符，也把“继续处理”与主任务分离。改为在现有全屏任务内容区显示等待信息和继续入口，并覆盖扫描完成后的丢弃确认。
- `minor`：流水关联创建状态的面板标题在正文重复一次。移除正文重复标题，保留固定面板标题和正文分隔。
- `minor`：Regular/Wide 流水详情进入编辑/删除/关联任务时同时显示标题关闭和任务内取消。隐藏重复关闭，只读详情保留标题关闭，Compact 保留全屏关闭。
- `minor`：关联创建和删除范围用例依赖视口外的语义代理和不存在的 Web `aria-checked` 属性。测试改为滚动实际面板正文，再以可见选择状态截图变化验证范围切换；API 调用仍用于确认操作边界。
- `minor`：日期筛选关闭后，Compose Web 保留隐藏的语义镜像根节点，导致对话框根 testTag 仍存在；这不是可见面板未关闭。日期用例改为验证面板内容语义节点已移除、截图变化和筛选请求结果，不再用根节点计数判断打开状态。
- `major`：第二轮视觉与业务复核发现 Compact 只读流水详情、删除范围确认及关联移除确认复用全屏任务容器。M3 将只读细节和短确认为基础对话框；全屏应留给 Compact 编辑、关系创建等含暂存输入的任务。将只读详情改为居中限宽基础对话框；删除和关联移除在同一基础详情对话框内切换确认状态，保留原有范围、取消、确认和异步错误行为。实施及三尺寸回归后复审。
- `major`（2026-10-18 Web 基线复审）：Compact 导入进入“关系配对”后，标题栏“确认导入”绑定到 `runPrimaryAction`；该阶段分支为空，实际点击不提交。全流程浏览器用例停留在关系配对页，已确认是产品业务缺陷，需改为调用 `commitImport()`，并验证成功状态、重复提交保护和失败重试。
- `major`（2026-10-18 Web 基线复审，待定位）：Regular 夜间主题文件选择页的捕获画面中，上传区标题、格式说明和按钮文字未呈现为可辨识的亮色文字；亮度断言最大值为 41。语义快照仍有这些文字，需检查实际绘制节点与截图定位，并修复/复验 768 px 夜间主题。
- `minor`（Web 测试合同过时）：流水只读详情在 Compact 当前显示居中、左右留白的基础对话框（实测左边界 31 px），符合本 change 的 M3 行为；现有断言仍要求铺满屏幕，改为检查基础对话框边界，并保留新增/编辑/关系创建 Compact 全屏任务断言。
- `minor`（Web 测试交互驱动不足）：编辑草稿与关联影响用例未能清空 Compose Web `contenteditable` 输入，导致备注被保留为旧文本、金额被追加为 `28.501.00`；修正测试输入驱动后再验证草稿保留、影响确认与防重复提交，不以这两次运行判定业务实现通过或失败。
- `minor`（Web 语义代理断言失准，逐项复核中）：详细筛选、ChoicePicker、批量分类、批量删除、导入丢弃提示与关系阶段用例有的定位到隐藏语义副本、有的断言旧 testTag/已移除页脚。页面快照显示部分目标状态已可见；测试改用实际可见界面、请求结果和操作后状态，不使用语义根节点计数作为唯一关闭证据。账户筛选、菜单选择后收起状态仍需浏览器复核，暂不一概归为测试问题。
