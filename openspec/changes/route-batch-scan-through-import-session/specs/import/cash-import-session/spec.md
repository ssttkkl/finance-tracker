## ADDED Requirements

### Requirement: 批量扫描与密码重试共用临时导入会话

系统 MUST 将包含多份文件的现金账单扫描及对应的密码重试绑定到同一个当前用户、工作区隔离的临时导入会话。首次批量扫描 MUST 返回可继续用于预览和确认的 `import_token`；文件需要密码时，重试 MUST 使用该令牌读取已暂存文件。扫描和密码重试 MUST NOT 写入账户、账单账户映射、现金流水、交易关系或收支投影。

#### Scenario: 批量扫描返回会话令牌

- **WHEN** 使用者通过批量扫描入口提交一组现金账单文件
- **THEN** 系统 MUST 返回不透明的 `import_token`、每个文件的识别状态和合并后的来源账户分组
- **AND** 该令牌 MUST 可用于同一批文件的账户映射及流水预览
- **AND** 扫描期间 MUST NOT 写入业务账本数据

#### Scenario: 使用同一会话重试需要密码的文件

- **WHEN** 批次中有文件需要密码，使用者提交该文件对应的密码并继续扫描
- **THEN** 系统 MUST 使用原 `import_token` 和已暂存文件完成重试
- **AND** 不得要求重新上传其余文件或创建第二个导入会话
- **AND** 重试期间 MUST NOT 写入业务账本数据
