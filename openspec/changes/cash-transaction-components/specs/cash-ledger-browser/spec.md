## ADDED Requirements

### Requirement: 收支投影按父流水展示并支持组成项账户证据
收支投影 MUST 以父流水作为一笔业务的展示单位，同时读取组成项和已确认关系计算金额、账户筛选及证据详情。aggregate 投影不得伪造单一账户归属；详情 MUST 展示组成项账户分配。

#### Scenario: 组合支付列表和账户筛选
- **WHEN** 一个父流水包含支付宝零钱和银行卡两个组成项
- **THEN** 全局列表 MUST 展示一笔父级业务，按账户筛选时 MUST 能分别命中对应组成项

#### Scenario: 组成项变更重建投影
- **WHEN** 使用者修改组成项账户或金额
- **THEN** 活动投影版本 MUST 更新，旧分页游标 MUST 失效，父级总额与组成项分配保持一致
