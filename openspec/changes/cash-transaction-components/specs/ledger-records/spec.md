## MODIFIED Requirements

### Requirement: 账本记录保留可审计来源而不双写
账单派生记录 MUST 在自身父流水行上保存导入渠道、业务行标识和来源行快照。支付组成项 MUST 保存账户分配、金额、币种和稳定顺序，但不得复制或改写来源行快照；系统 MUST NOT 把组成项当作额外来源业务行或破坏父流水幂等身份。

#### Scenario: 组合账单行保存来源
- **WHEN** 一条账单行解析出多个支付组成项
- **THEN** 系统 MUST 只创建一条父现金流水，完整来源行快照保留在父流水上，组成项保存派生分配

### Requirement: 账本数值和时间跨后端等价
账本记录及支付组成项的金额、数量、汇率、成本和费用 MUST 使用精确十进制表示；组成项币种 MUST 与父流水一致。PostgreSQL 与 SQLite MUST 对合法值、非法值、空值和查询排序产生等价的用户可见结果。

#### Scenario: 组成项金额精确往返
- **WHEN** 写入多个组成项且金额总和包含高精度小数
- **THEN** 两个后端 MUST 原样返回每个组成项金额和父流水守恒结果，不得经过二进制浮点转换
