## 剩余热路径的实现边界

在原工作量内减少同次调用的重复工作：普通容器内精确标量直接复制；独占普通容器的序列化不重复赋值，子类保留完整协议。资金分组摘要仅对精确字符串参数作调用内复用；支付宝解析缓存按文件限制 128 个参数组合，先检查原始账户、文件摘要、解析器版本、金额、支付方式和商品说明的精确类型，其他类型走原逻辑。

无既有记录、单文件同来源和账户、唯一可靠编号及位置、无文档分页证据时，可逐行完成原完整字段校验后直接得到新增结果；标准非分页文件证据可直接保留；未知证据类型、未知字段转换协议及其他输入保留通用来源算法。通用算法只在实际比较时计算规范内容摘要。负向消费的自动关系候选可排除明确属于现有 `source_group=other` 的非空来源，未知／空白来源保留文本回退；银行、平台、硬编号和既有闭包不裁剪。通用商户退款由显式退款种子发起，全负消费种子不会触发该分支；以强制完整候选的最终计划差分约束此条件。

小批当前收支对象读取可在正常 autoflush 下联合读取成员与对象；连接始终包含工作区。ORM 成员指向与联合行不一致、缺对象、禁用 autoflush 或超过 400 个编号时保留原二阶段读取，不能改变会话身份、待写变更和损坏数据的错误。单次记录准备复用无写入间隔的对象及成员快照。分类 JSON 仅在数据库原值精确为 `{}` 或 `[]` 时直构等价结果，其他形状保留原合并。

没有 accepted 关系且全部为精确 `CashProjectionFact` 时，正式单笔可直接构造与原通用算法逐字段相同的投影；草稿、输入校验、最终排序和完整性保持。关系图空边优化必须先完成全部组成项和资金引用校验，仅精确事实、组成项、Decimal 与标识字符串走快路径；子类继续原遍历协议。所有写后重验和错误翻译保留。不调整 UI、财务规则、来源准入、runner 或依赖；时间预算仅按下方授权表调整。

## 当前 runner 的预算检查成本

万行剖析中 JSON 预算递归占用明显；精确普通 JSON 可在单次调用内使用局部剩余预算，避免每个标量重复读写列表。必须保留字典／列表各自的负预算和深度检查顺序、Unicode／巨大整数／非有限浮点错误、异常时剩余预算及重复引用逐次计费。遇到子类、未知类型、日期／DTO 或输入包含预算列表自身时，丢弃试算并完整回退原算法；回退前不得执行自定义协议，不接受 Decimal。用修改前算法作差分基准，比较结果、错误、剩余预算和回调顺序。关系提交每次确认约有 79 条 SQL。无使用者的顶层当前对象读取仅在对象编辑或成员补丁时保留；关系仓库对同次已完整读取的父行执行原创建方式纯校验，不重复查询。上下文的组成项与当前资金关联可用同工作区、已接受及活动条件的外连接一次读取，保留无资金组成项、全部有效资金行和排序。投影在写后重新加载完整图、当前对象版本及成员可解析性；不省去版本快照以免改变损坏数据或待写 ORM 的失败行为。拆分假设图照常构建，未知或损坏数据的错误不掩盖。不跨写入复用上下文。

## Runner 剖析后的实现边界

同条件诊断确认 PostgreSQL 冷统计下的关系端点／递归闭包／当前展示引用查询扫描无关关系与成员。优化查询表达式，使有界端点或成员先定位，再读取对应关系／投影；所有 SQL 仍限定工作区，当前引用仍限定活动数据集，递归闭包保留双向、去重、循环及批界。SQLite 保持已验证的查询策略；不通过夹具 ANALYZE、减少背景数据或修改 runner 修复性能。写入前后上下文仍分别读取。

万行预览的主要 Python 成本包含计划转换、JSON 预算及来源身份摘要。普通容器转换直接保留精确空字典／列表和标量，空元组仍分别产生新列表；子类继续原迭代、赋值和复制协议。JSON 预算保留已经验证的实现，错误顺序、深度和剩余预算与冻结原算法差分。来源文件摘要仅在同一文件、精确字符串身份下按相同账户范围复用；每行仍构造并验证来源出现，其他类型保持原路径，不缓存字段／财务结果或跨调用值。

资金解析和操作规划各在本次调用内使用有界的成功校验缓存。键覆盖转正式校验实际读取的全部字段、字段存在性、每个组成项的已知字段与精确输入类型；金额使用精确 Decimal 元组，时间仅允许字符串或 UTC 内建 datetime。只有完整统一校验成功才记录，失败、额外组成项字段、容器／标量子类和自定义时区继续完整函数。缓存最多 256 项，每次调用重建，不能复用到账户、权限、当前修订或持久化检查；公开统一财务校验函数保持不变。

GC 分阶段诊断确认大量存活容器被重复扫描；禁止暂停解释器全局 GC、调整阈值或把回收移出验收计时。仅对精确普通容器、单一操作成员且关系／问题／字段差异均为空的独立详情，增加不创建公开 DTO 的只读校验。入口、操作归属、组成项及虚拟编号转换错误仍逐项检查；未知协议或复杂详情回原解析与公开校验器。原公共详情输出及复制边界不变，以强制原路径的差分和真实服务性能验证约束。

独立性能复核定位到准备结果在整段最终图与展示构建期间保活完整资金扫描和来源出现图。内建导入构建器将准备、来源身份补齐、账户读取和完整候选读取收束为短生命周期 helper，只把操作、逐行决定、候选编号、候选集合及账户快照交给后续构建。候选查询与账户读取顺序不变，没有中间写入，后续上下文仍完整读取；外部注入的来源计划不清空或修改，公共维护入口仍自行查询候选。以弱引用证明内部准备图在最终快照构建前释放，并保留完整匹配与来源／资金回归。
