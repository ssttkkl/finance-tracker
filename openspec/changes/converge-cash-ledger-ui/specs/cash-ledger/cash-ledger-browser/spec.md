## MODIFIED Requirements

### Requirement: 收支账本表格列与交易信息层级

Compose 收支账本在 `REGULAR` 与 `WIDE` MUST 使用一致的桌面表格列顺序：选择框、发生时间、账户、交易信息、分类、流水类型、金额。上述列宽 MUST 依次按 5、12、15、24、12、11、13 的相对权重分配剩余宽度；行操作由整行点击承担，MUST NOT 单设行操作列。交易信息列 MUST 先显示交易对方，再在其下显示备注；任一字段缺失时 MUST 保留其行位置并以短横线表示。`COMPACT` MUST 继续使用流水卡片，并让备注紧接交易对方显示。

#### Scenario: Regular 与 Wide 使用一致的表格列

- **GIVEN** 收支账本在 `REGULAR` 或 `WIDE` 窗口展示流水
- **WHEN** 列表含有可选择流水
- **THEN** 表格 MUST 依次呈现选择、发生时间、账户、交易信息、分类、流水类型和金额
- **AND** MUST NOT 出现单独的行操作列，整行点击承担打开详情
- **AND** 交易信息列 MUST 在同一列内先显示交易对方，再显示备注
- **AND** 交易对方或备注缺失时 MUST 保留两行结构

#### Scenario: Compact 卡片显示交易对方和备注

- **GIVEN** 收支账本在 `COMPACT` 窗口展示流水卡片
- **WHEN** 流水包含交易对方和备注
- **THEN** 卡片 MUST 将交易对方和备注相邻展示，交易对方先于备注
- **AND** 缺失值 MUST 使用短横线占位

### Requirement: 证据详情只展示可核对业务信息

收支详情 MUST 优先展示金额、交易对方、发生时间、账户、收支分类路径和备注；来源、原始账单和关联记录等核对信息必须进入详情的次级区域。收支分类必须作为整笔收支详情的共享字段查看和修改，不得把成员流水展示为互相冲突的分类。原始账单次级区域 MUST 按来源返回内容展示字段名与值，允许出现技术字段名与枚举原文；该区域之外的主详情与列表 MUST NOT 暴露投影、数据库代理键、分类 ID 路径、底层审计表结构或不存在的角色。原始账单区域 MUST 与主详情分层，默认位于详情末尾。

#### Scenario: 查看单源投影

- **WHEN** 使用者打开没有采用关系的单源投影
- **THEN** 详情 MUST 展示该记录自身字段和收支分类或无分类状态，导入渠道进入次级核对信息，且不得显示空的关联记录区域

#### Scenario: 查看关系投影

- **WHEN** 使用者打开采用同笔支付或退款关系的投影
- **THEN** 详情 MUST 显示整笔收支详情共享的分类，并在次级核对信息中逐条显示关联记录，不得用实现术语解释组成方式

#### Scenario: 查看原始账单

- **WHEN** 使用者展开某条流水的账单原文
- **THEN** 字段名与值 MUST 按来源返回内容原样展示，允许技术字段名与枚举值
- **AND** 主详情与列表 MUST 继续使用用户可读的账户、分类与类型，不得把代理键混入主要字段

### Requirement: 新工作区可直接浏览空账本

系统 MUST 在创建或首次切换到合法工作区后提供可读取的空收支账本。工作区没有现金流水时，列表、筛选选项和月份汇总 MUST 返回合法空结果，不得把缺少活动数据集当作用户可见系统错误。账本空状态 MUST 区分“没有任何流水”与“当前筛选没有结果”：前者提供“记一笔”“导入账单”入口，后者提供“清除筛选”。

#### Scenario: 创建工作区后首次打开收支页

- **WHEN** 使用者注册后创建一个没有任何现金流水的新工作区并打开收支页
- **THEN** API MUST 返回成功的空列表合同，页面 MUST 显示空状态和“记一笔”“导入账单”等核心入口

#### Scenario: 切换到没有流水的工作区

- **WHEN** 使用者从已有工作区切换到一个尚未产生现金流水的工作区
- **THEN** 收支页 MUST 在当前工作区边界内返回空结果，不得展示上一个工作区的记录或 `projection.unavailable`

#### Scenario: 初始化失败

- **WHEN** 空账本初始化因数据库或投影构建错误失败
- **THEN** 系统 MUST 保留工作区创建事务的一致性，并返回可重试的存储/初始化错误；不得伪造成功的账本数据

#### Scenario: 筛选没有结果

- **WHEN** 账本有流水，但当前搜索或筛选条件没有匹配项
- **THEN** 页面 MUST 显示“没有匹配的收支记录”并提供清除筛选，不得提示账本还没有流水
