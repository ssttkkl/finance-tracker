## ADDED Requirements

### Requirement: 导入配对决定绑定预览计划的合法候选

导入会话中的自动配对、待手动配对、跳过和拒绝配对决定 MUST 绑定到该会话保存的预览配对计划。人工指定的对侧流水必须是对应建议的合法候选，且锚点、工作区和稳定建议标识必须一致；使用者改变关系种类仍 MUST 通过既有关系不变量及候选约束验证。仅匹配建议标识不得使不属于该建议的对侧流水成为合法决定。

#### Scenario: 人工选择不属于建议的对侧流水

- **WHEN** 确认请求为一个有效建议标识提交了不在其候选范围内的对侧流水
- **THEN** 系统 MUST 拒绝该请求，且不得创建或修改导入流水、交易关系或收支投影

### Requirement: 缓存计划应用仍保持关系不变量

系统 MUST 在缓存预览配对计划映射为实际现金流水后，继续校验关系端点、精确金额、剩余退款金额、工作区隔离、端点占用、关系图互斥和投影一致性。缓存计划不得绕过既有关系不变量，也不得因再次运行候选扫描而静默改变使用者已经核对的建议。

#### Scenario: 缓存建议与当前端点约束冲突

- **WHEN** 预览配对计划的任一关系在确认事务中不再满足端点或关系图约束
- **THEN** 系统 MUST 回滚整个确认导入并返回重新确认配对结果，不得选择另一条流水自动替代该建议
