## ADDED Requirements

### Requirement: 导入会话确认采用预览配对计划

Web 导入会话在使用者完成账户映射确认并生成配对建议时，系统 MUST 为该会话保存服务端拥有的预览配对计划。计划必须以稳定的来源业务行引用和关系建议标识表达导入行、既有流水、合法对侧范围与关系上下文摘要；账单内容、解析结果和账户映射在该会话的预览后保持冻结，不得在配对确认步骤中重新解释为新的导入输入。

#### Scenario: 确认采用同一份预览计划

- **WHEN** 使用者提交一份仍适用的预览配对计划及其配对决定
- **THEN** 系统 MUST 在一次原子导入中将该计划的稳定引用解析为实际现金流水并应用相同建议，不得再次运行配对规则来替换或补充建议

#### Scenario: 未生成预览时直接确认

- **WHEN** Web 导入会话尚未保存预览配对计划，或该计划已丢失
- **THEN** 系统 MUST 拒绝确认并要求重新确认配对，不得回退到重新运行配对规则的旧导入路径

### Requirement: 关系上下文变化要求重新确认配对

确认导入时，系统 MUST 在写入账单、账单账户映射、交易关系或收支投影前校验预览配对计划依赖的当前关系上下文。若上下文不再适用，系统 MUST 以可识别的重新确认配对结果结束请求，且不得写入任何上述状态；该结果不得把使用者送回选择文件或账户映射步骤。

#### Scenario: 可配对流水在确认前变化

- **WHEN** 使用者查看配对建议后，当前工作区中影响该计划的可配对流水或既有交易关系发生变化
- **THEN** 系统 MUST 不创建或更新导入流水、账户映射、交易关系和收支投影，并要求使用者重新确认配对
