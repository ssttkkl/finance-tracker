## ADDED Requirements

### Requirement: Compose 单值选择字段使用锚定弹出菜单

共享 Compose 页面中的单值选择字段 MUST 展示字段标签与当前值，并在触发时于字段附近弹出选项菜单。菜单 MUST 覆盖页面内容，不得撑开或改变字段、卡片、对话框及其父区域的尺寸或位置。Web、Android 和 iOS MUST 保持相同的选项、标签、当前值、选择结果和关闭语义；选择选项后菜单 MUST 关闭并提交对应值，点击菜单外部或按 Escape / Native 系统返回 MUST 关闭菜单且保留当前值。禁用字段 MUST 不得展开菜单。

#### Scenario: 所有值选择字段以弹出菜单选择

- **WHEN** 使用者打开任一共享 Compose 单值选择字段
- **THEN** 字段附近 MUST 显示选项菜单，菜单内容 MUST NOT 进入页面原有布局流
- **AND** 展开前后字段及其父区域的几何尺寸 MUST 保持不变
- **AND** 选择、点击外部或按 Escape 关闭后，字段 MUST 显示正确值且页面可继续操作

#### Scenario: 禁用的值选择字段不能展开

- **WHEN** 单值选择字段处于禁用状态
- **THEN** 字段 MUST 保留禁用语义
- **AND** 点击字段 MUST NOT 打开选项菜单或提交新值

### Requirement: Compose 账单导入映射以统一弹出菜单和账户摘要呈现目标

Compose Web、Android 和 iOS 的账单导入账户映射 MUST 为目标账户和新账户类型提供弹出式下拉菜单。菜单 MUST 锚定在触发控件附近并覆盖映射内容；展开和关闭 MUST NOT 改变映射卡片的尺寸或位置。三端 MUST 使用相同的选项、标签、选择结果和关闭语义。选择选项后菜单 MUST 关闭并提交该次映射选择；点击菜单外部、按 Escape 或 Native 系统返回关闭菜单时 MUST 保留当前选择。

目标账户菜单中的每个现有账户和可复用的新账户草稿 MUST 显示账户名称、账户类型和币种。选择账户后，目标账户控件 MUST 保留相同的名称、类型和币种信息。映射到现有账户时，这些信息 MUST 为只读，且 MUST NOT 在控件下方重复显示账户摘要。若来源账户组含有该账户尚未支持的币种，页面 MUST 保留现有的币种扩充提示。

选择「创建新账户」后，目标账户控件 MUST 继续显示固定的「创建新账户」标签，不得将当前行草稿添加为「新账户：名称」选项。创建该草稿的映射行 MUST 在控件下方显示推导的账户名称、类型和来源币种，并提供「修改」操作；不得在映射行内展开名称和类型编辑字段。再次选择当前已选的「创建新账户」时 MUST 保留已有草稿编辑，不得重置名称或类型。其他来源组可以选择该共享草稿；选择后其账户信息 MUST 显示在目标账户控件内，MUST NOT 在控件下方重复显示账户摘要，并 MUST 保留「修改」操作以支持从任一引用行编辑共享草稿。点击「修改」MUST 打开 Material 3 模态对话框，其中只允许编辑名称和账户类型；币种仍由引用该草稿的来源账户组决定。编辑对话框高度 MUST 随表单内容收缩，不得通过固定高度或空白占位扩大。账户类型选择 MUST 遵循共享单值选择字段的弹出菜单合同，且 MUST NOT 改变对话框尺寸。两端的选项、当前值、Escape/返回关闭及选择结果 MUST 一致，关闭菜单不得阻断对话框操作。点击「完成」MUST 将名称和类型更新同步到全部引用行；点击「取消」MUST 丢弃本次未完成编辑并关闭对话框。

#### Scenario: 菜单覆盖映射内容且不改变布局

- **WHEN** 使用者在 `COMPACT`、`REGULAR` 或 `WIDE` 打开目标账户或账户类型菜单
- **THEN** 菜单 MUST 锚定在触发控件附近并覆盖映射内容
- **AND** 对应映射卡片的尺寸和位置 MUST 保持不变
- **AND** 选择选项后菜单 MUST 关闭并更新选择结果
- **AND** 点击菜单外部、按 Escape 或 Native 系统返回关闭菜单时 MUST 保留原选择

#### Scenario: 账户选项和已选控件展示完整信息

- **WHEN** 使用者展开目标账户菜单或选中现有账户、共享新账户草稿
- **THEN** 每个账户选项和已选控件 MUST 显示账户名称、账户类型和币种
- **AND** 现有账户信息 MUST 只读
- **AND** 现有账户或共享草稿的完整账户信息 MUST NOT 在控件下方重复显示
- **AND** 现有账户不得显示新账户草稿编辑操作
- **AND** 若来源账户组涉及账户尚不支持的币种，页面 MUST 显示对应的币种扩充提示

#### Scenario: 创建新账户并展示推导信息

- **WHEN** 使用者为一个来源账户组选择「创建新账户」
- **THEN** 目标账户控件 MUST 保持显示「创建新账户」
- **AND** 该行不得出现将此草稿再次列出的「新账户：名称」选项
- **AND** 映射行 MUST 在控件下方显示草稿名称、账户类型和来源币种以及「修改」操作
- **AND** 映射行 MUST NOT 显示名称或账户类型的内联编辑控件

#### Scenario: 重选创建账户不重置草稿

- **GIVEN** 使用者已修改当前「创建新账户」草稿的名称或类型
- **WHEN** 使用者再次选择当前已选的「创建新账户」
- **THEN** 草稿名称和类型 MUST 保持不变

#### Scenario: 复用共享新账户草稿

- **WHEN** 使用者为其他来源账户组选择已创建的新账户草稿
- **THEN** 该草稿的名称、类型和币种 MUST 显示在已选目标账户控件内
- **AND** 该行 MUST NOT 在控件下方重复显示账户信息
- **AND** 该行 MUST 保留「修改」操作，编辑后同步更新共享草稿的全部引用

#### Scenario: 修改共享新账户草稿

- **WHEN** 使用者从任一引用行打开「修改」对话框并完成名称或类型编辑
- **THEN** 页面 MUST 更新共享新账户草稿
- **AND** 当前导入会话内引用该草稿的全部映射行 MUST 显示更新后的名称和类型
- **AND** 草稿币种 MUST 保持由来源账户组决定，不得在对话框中编辑

#### Scenario: 取消新账户草稿编辑

- **WHEN** 使用者修改新账户草稿字段后点击「取消」
- **THEN** 对话框 MUST 关闭
- **AND** 共享新账户草稿及其引用行 MUST 保持打开对话框前的值

#### Scenario: 类型菜单不撑高编辑对话框

- **WHEN** 使用者打开新账户编辑对话框并展开账户类型菜单
- **THEN** 编辑对话框高度 MUST 由表单内容决定，不含用于菜单的空白占位
- **AND** 类型菜单 MUST 锚定账户类型字段并覆盖对话框内容
- **AND** 展开或关闭菜单 MUST NOT 改变编辑对话框尺寸

### Requirement: 账单导入主要操作显示匹配图标

账单导入的主要操作按钮 MUST 同时保留可见文字标签并显示与其操作含义匹配的图标；图标 MUST NOT 替代按钮文字。收支账本主页的「导入账单」FAB 菜单项 MUST 使用清楚表达导入/收件的图标，不得呈现为文件导出动作。

#### Scenario: 导入操作按钮保留文字并显示匹配图标

- **WHEN** 使用者在导入流程查看可执行操作
- **THEN** 选择文件、移除文件、返回、继续、确认导入、完成和编辑等主要操作 MUST 同时显示文字及含义匹配的图标
- **AND** Compact 布局中的图标 MUST NOT 遮挡文字或导致页面水平溢出
- **AND** 收支账本主页的「导入账单」FAB 菜单图标 MUST 表达文件导入/收件方向

## MODIFIED Requirements

### Requirement: Compose cash import follows the confirmed secondary-page design

Compose 账单导入页 MUST 以 Compose 实现为视觉事实源，并遵循本规格定义的信息层级和响应式布局。`REGULAR` 和 `WIDE` MUST 先显示页面标题，再显示右侧关闭按钮；`COMPACT` MUST 先显示左侧返回按钮，再显示标题。二级页面标题栏高度 MUST 按 `COMPACT` / `REGULAR` / `WIDE` 分别为 72 dp、78 dp 和 84 dp。`REGULAR` 与 `WIDE` 模态框圆角 MUST 分别为 22 dp 和 24 dp，且不得添加额外阴影。关闭或返回按钮 MUST 遵循 Material 3 焦点行为，并使用 FinanceTheme 焦点颜色。

四步指示器 MUST 使用等宽步骤、编号或完成状态圆形标记及其下方标签，并独立于受 720 dp 宽度限制的阶段内容，`REGULAR` / `WIDE` 两侧内边距 MUST 为 36 dp，`COMPACT` MUST 为 12 dp。文件选择、账户映射和流水核对内容 MUST 居中且最大宽度为 720 dp；关系核对 MUST 使用可用容器宽度，并以来源到目标的卡片或行展示每项关系。页面 MUST 保留既有扫描、账户映射、流水核对、分配、关系类型、候选选择、拒绝与恢复、错误处理及确认语义。

完整账单导入路由 MUST 使用应用当前已配置的 FinanceTheme 颜色角色，覆盖导航栏、顶栏、路由背景和导入界面；不得强制使用浅色主题。页面 MUST 在浅色与夜间模式下为文字、表面、表单、菜单、遮罩、加载、错误及完成状态提供可读对比。`REGULAR` / `WIDE` 模态框背景遮罩 MUST 使用现有深色遮罩 token 的 38% 透明度；模态框 MUST 阻止背景交互、保持模态键盘焦点并支持 Escape 或返回操作关闭。所有共享组件颜色 MUST 从当前 Compose 主题作用域解析。使用者离开账单导入页后，应用 MUST 恢复已配置的系统外观。

关系筛选器 MUST 显示全部、待确认和已匹配的数量。关系卡片 MUST 以既有的紧凑层级展示来源与目标流水，不得常驻展示账户名称或重复的字段标题；关系时间 MUST 使用本地时间的 `MM 月 dd 日 · HH:mm` 格式。待确认的目标流水 MUST 使用一个显示“选择流水”的候选下拉框，不得再添加说明文案或独立的可见选择操作。候选选项 MUST 锚定在选择框附近以浮层展示，打开或关闭时 MUST NOT 改变关系卡片及列表的尺寸或位置。选择候选项 MUST 关闭浮层并更新目标流水与关系数量；按 Escape 或点击浮层外部 MUST 关闭浮层且保留当前选择。待确认状态 MUST 使用 FinanceTheme 的警告语义 token。`COMPACT` 关系卡片 MUST 将来源和目标并列展示，并把状态放在下方；`REGULAR` / `WIDE` MUST 将关系状态放在关系行末尾。较少使用的关系类型以及拒绝/恢复操作 MAY 放入可通过键盘操作的辅助操作入口，并以状态标签呈现。

二级页面页脚 MUST 只在 `COMPACT` 显示分隔线；`REGULAR` / `WIDE` 不显示分隔线。`COMPACT` 页脚说明 MUST 显示在操作行上方，顶部与底部内边距分别为 8 dp 和 16 dp；`REGULAR` / `WIDE` 页脚内容的顶部与底部内边距 MUST 分别为 16 dp 和 24 dp。映射、核对、配对阶段的“上一步” MUST 使用描边次按钮；`REGULAR` / `WIDE` 的操作按钮 MUST 靠右对齐，`COMPACT` 的“上一步”和主操作 MUST 分别靠左和靠右对齐。`COMPACT` 文件选择阶段 MUST 将放弃提示显示在下一步操作上方。界面展示的文件格式 MUST 为 `CSV · XLSX · PDF`，同时保留现有 XLS 导入支持。

#### Scenario: 在 Wide 尺寸查看账单导入

- **WHEN** 使用者在 `WIDE` 窗口打开账单导入页
- **THEN** 页面 MUST 显示左侧标题、右侧关闭按钮和带有步骤标签的四步指示器
- **AND** 系统外观为夜间主题时，导航栏、顶栏和导入界面 MUST 使用 FinanceTheme 的夜间语义颜色并保持可读对比
- **AND** 模态框背景 MUST 使用现有的 38% 遮罩 token
- **AND** 文件选择、账户映射和流水核对内容 MUST 居中且最大宽度为 720 dp，关系核对 MUST 使用可用容器宽度
- **AND** 待确认关系 MUST 在来源到目标的行中提供一个候选选择器；其浮层 MUST 覆盖在内容之上且不撑开关系行，选中后关系类型与拒绝/恢复操作 MUST 仍然可用
- **AND** 已匹配筛选 MUST 包含自动匹配和用户确认的关系，被拒绝的关系 MUST 仍显示在全部筛选中
- **AND** 页脚 MUST 没有分隔线，底部内边距 MUST 为 24 dp
- **AND** 映射、核对和配对阶段的页脚操作按钮 MUST 靠右对齐
- **AND** “上一步” MUST 使用描边次按钮

#### Scenario: 在 Regular 尺寸查看账单导入

- **WHEN** 使用者在 `REGULAR` 窗口打开账单导入页
- **THEN** 标题栏 MUST 高 78 dp，模态框 MUST 使用 22 dp 圆角且没有额外阴影
- **AND** 页面标题 MUST 位于关闭按钮之前
- **AND** 候选选择浮层 MUST 覆盖在关系内容之上；打开时关系卡片尺寸 MUST 保持不变，选择候选后 MUST 更新关系目标
- **AND** 页脚 MUST 没有分隔线，底部内边距 MUST 为 24 dp
- **AND** 映射、核对和配对阶段的页脚操作按钮 MUST 靠右对齐
- **AND** “上一步” MUST 使用描边次按钮

#### Scenario: 在 Compact 尺寸查看账单导入

- **WHEN** 使用者在 `COMPACT` 窗口打开账单导入页
- **THEN** 页面 MUST 使用全屏界面，并先显示返回按钮再显示标题
- **AND** 文件选择阶段的放弃提示 MUST 显示在下一步操作上方
- **AND** 阶段内容和关系卡片 MUST 保持单列或适当重排，页面 MUST 没有横向溢出
- **AND** 所有导入决策和结果 MUST 与 `REGULAR` / `WIDE` 一致
- **AND** 关系卡片 MUST 横向并列显示来源与目标，且不得造成横向溢出
- **AND** 候选选择浮层 MUST 锚定在选择框附近且不改变卡片高度；选择后 MUST 更新目标和关系数量
- **AND** 在映射、核对和配对阶段，“上一步” MUST 靠左、“下一步”或主操作 MUST 靠右；“上一步” MUST 使用描边次按钮

#### Scenario: 离开账单导入后恢复系统外观

- **WHEN** 使用者从账单导入页返回其他应用路由
- **THEN** 目标路由 MUST 使用已配置的系统外观

#### Scenario: 关闭候选浮层而不改变选择

- **WHEN** 使用者按 Escape 或点击候选浮层以外的位置
- **THEN** 候选浮层 MUST 关闭
- **AND** 当前目标流水及关系数量 MUST 保持不变

#### Scenario: 导入流程在夜间主题下保持可读

- **GIVEN** 应用当前配置为夜间主题
- **WHEN** 使用者浏览文件选择、账户映射、预览、关系审查、编辑对话框或完成状态
- **THEN** 页面、表面、文字、表单、菜单、遮罩和状态颜色 MUST 遵循 FinanceTheme 的夜间语义角色
- **AND** 文字、图标与其容器之间 MUST 保持可读对比
- **AND** 页面 MUST NOT 显示被浅色专属颜色覆盖的卡片、菜单、对话框或完成状态
