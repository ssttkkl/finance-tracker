## ADDED Requirements

### Requirement: 临时预览容量有界且拒绝后保留当前会话

系统 MUST 为解析内容、单会话完整暂存对象及本地内存暂存总量保留有限预算。默认单会话完整序列化预算为 128 MiB，解析内容预算为 25 MiB，本地内存暂存总量为 256 MiB；文件数量、单文件限制、有效期与工作区隔离继续按既有合同执行。容量检查 MUST 包括实际序列化后的内容，超限不得发布部分计划、写业务账本、改变旧文件或选择、增加修订或延长有效期。

#### Scenario: 受预算支持的多文件整批预览

- **WHEN** 一组已解析文件的解析内容和完整预览均满足预算，使用者选择有效资金账户并请求预览
- **THEN** 系统 MUST 允许在同一会话核对完整预览并继续一次最终确认，不因旧容量限制拒绝新预算内的内容

#### Scenario: 完整预览超过单会话预算

- **WHEN** 生成的完整预览超过单会话预算
- **THEN** 系统 MUST 返回 422 和 `import_session_draft_too_large`，提示本次导入内容过多、减少文件后重试，不得误报导入参数无效
- **AND** 现有文件、选择、计划、修订及有效期 MUST 全部保留
- **AND** Compose MUST 返回第一步文件准备后再通过现有 Snackbar 显示一次超限原因，不在页面顶部重复常驻展示，重组或重进页面不得重播旧提示，允许使用者继续选择、替换或移除文件；不得只返回页面却仍禁止文件操作，也不得为修改文件先重复生成同一个超限预览
- **AND** 文件集合变化后 MUST 继续保留有效账户选择，按既有来源引用和选择失效规则重新核对，不清空整次导入或自动提交

#### Scenario: 本地暂存总容量不足

- **WHEN** 本地内存暂存无法在总量预算内发布新对象
- **THEN** 系统 MUST 返回 503 和 `import_session_capacity_exceeded`，提供可重试的安全错误，不得发布部分对象或更改当前会话
