# 数据模型：持仓行情报价编排

本 feature 不新增持久化实体、表或迁移。以下对象是一次查询内的内存合同。

## 报价请求

| 字段 | 说明 | 规则 |
|------|------|------|
| `identity` | 既有资产标识 | 由当前持仓 ticker 提供，按既有类型规则规范化。 |
| `kind` | `AssetKind` | 与既有 `cash`、`security`、`crypto`、`prediction_market` 一致。 |
| `request_key` | 去重键 | `kind` 与规范化 `identity` 的组合；仅相同键共享单价。 |
| `quantity` | 单个仓位持有数量 | 不参与单价去重；用于将共享单价计算为各仓位市值。 |

## 报价分组

| 字段 | 说明 | 规则 |
|------|------|------|
| `source` | 提供行情的数据源 | 由资产类型与现有路由决定。 |
| `requests` | 该数据源处理的唯一报价请求 | 同一 `request_key` 只出现一次。 |
| `deadline` | 查询的绝对单调时钟截止时间 | 所有分组共享；不得延长总预算。 |
| `max_in_flight` | 该分组最大同时工作数 | 固定配置；不得随仓位数量无界增长。 |

## 报价结果

沿用 `QuoteResult`，不改变以下字段语义：

| 字段 | 说明 |
|------|------|
| `unit_price` | 有效行情的精确十进制单价。 |
| `quote_currency` | 行情报价的计价币种。 |
| `market_value` | 单价乘以仓位数量的精确十进制结果。 |
| `status` | `complete`、`stale`、`partial` 或 `unsupported`。 |
| `reason` | 对未完成、空数据或不支持标识的可区分原因。 |

## 映射关系

- 一个**报价请求**可映射到一个或多个不同账户的仓位。
- 一个**报价分组**包含同一数据源的多个报价请求。
- 一个**报价结果**按请求键回填到所有对应仓位；每个仓位再按自身数量计算市值。
