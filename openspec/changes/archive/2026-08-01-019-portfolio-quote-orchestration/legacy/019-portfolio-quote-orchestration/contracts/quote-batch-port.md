# 报价批量 Port 合同

## 目的

为持仓查询提供按请求键返回逐项报价结果的能力。调用方不依赖特定数据源的 HTTP 形态。

## 输入

- 一组已校验的 `AssetRef`。
- 单调时钟截止时间或剩余超时。
- 可选的最大并发上限，仅由数据源适配器使用。

## 输出

- 每个输入 `AssetRef` 对应一个 `QuoteResult`，可按请求键检索。
- 有效单价必须为有限的 `Decimal`；`market_value` 按输入数量计算。
- 未返回、失败、超时或限流的项目必须保留为 `partial`，不得用其他项目的价格填充。
- 不支持的标识为 `unsupported`。

## 约束

- 结果不得包含凭据、账户名、完整持仓明细或原始外部响应。
- 批量实现可在一个数据源请求中返回多个项目；不支持批量的数据源必须应用固定并发上限。
- 调用方到达总截止时间后不得再提交新任务。已启动任务不得阻塞调用方返回。
- 单项 `quote` 与批量路径在相同数据源输入下必须产生相同的状态、单价和计价币种。
