## Why

Compose 收支账本的滑块与轨道视觉位置不一致：滑块贴近列表右缘，可见轨道却留在触控热区中线；滚动后，固定在上方的月份摘要还会盖住轨道。使用者因此看到右侧空白，且滚动条显示不完整。

## What Changes

- 将可见轨道平移到与滑块一致的位置，让三个窗口等级的轨道都贴近列表右缘。
- 调整滚动条与月份吸顶摘要的绘制层级，确保滚动条显示在摘要层上方。
- 保持触控热区、滚动定位和摘要内容不变。

## Scope

- Compose 共享账本页面及其浏览器回归覆盖。
- 更新收支账本主规格、功能地图与本变更验证记录。

## Non-goals

- 不调整筛选、分页、摘要数据、滚动条定位算法或视觉尺寸。
- 不修改 Legacy React Web 或 Expo Native 页面。

## Acceptance

- 在 `COMPACT`、`REGULAR` 和 `WIDE` 窗口滚动到账本月份摘要固定后，滚动条轨道仍显示在摘要上方。
- `COMPACT`、`REGULAR` 和 `WIDE` 窗口的可见轨道与滑块对齐，并贴近账本列表右缘。
- 滚动条仍可拖动，吸顶摘要和流水列表行为不变。
