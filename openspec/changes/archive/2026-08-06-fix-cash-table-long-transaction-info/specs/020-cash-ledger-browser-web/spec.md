## ADDED Requirements

### Requirement: 宽屏账本表格限制长交易信息

系统 MUST 在宽屏收支账本表格中为交易信息保留受限的单元格宽度。交易对方或备注超过该列可用宽度时，系统 MUST 以省略号截断显示，且不得因该字段扩大表格的可滚动宽度、挤出来源、经济类型、金额或证据入口。完整交易对方和备注 MUST 继续通过既有证据详情可查。

#### Scenario: 超长交易信息保持后续列可见

- **WHEN** 使用者在宽屏收支账本中浏览交易对方或备注包含超长连续文本的投影条目
- **THEN** 交易信息仅在自身列内以省略号显示，表格不因该字段产生额外横向溢出
- **AND** 来源、经济类型、金额和证据入口仍保留在表格容器内并可操作
