## MODIFIED Requirements

### Requirement: 收支账本标示投影来源
收支账本 MUST 为每个投影条目展示「来源」列。列表响应 MUST 提供 `source_types`，即当前投影快照中该条目全部成员记录非空 `source_type` 的按成员顺序去重集合。单源投影 MUST 显示自身导入渠道；关系投影 MUST 显示 `source_types` 全部值，并显示「关系投影」标记。来源缺失时 MUST 显示 `-`。前端 MUST 使用列表响应的 `source_types` 呈现表格来源；收支详情单源使用主记录 `source_type`，关系投影使用证据响应成员记录的同一去重规则，不得重新推断关系或来源。

#### Scenario: 展示单源投影来源
- **WHEN** 列表返回单源投影条目
- **THEN** 该条目的「来源」列显示其 `source_types` 唯一值或 `-`
- **AND** 不显示「关系投影」标记

#### Scenario: 展示关系投影来源
- **WHEN** 使用者查看关系投影条目
- **THEN** 列表和证据详情的「来源」均显示全部成员记录 `source_type` 的按成员顺序去重集合或 `-`
- **AND** 列表和收支详情均显示「关系投影」标记

#### Scenario: 在收支详情展示来源
- **WHEN** 使用者打开任一投影条目的证据详情
- **THEN** 「收支详情」以字段形式显示「来源」
- **AND** 单源投影使用主记录来源，关系投影使用全部成员来源的去重集合

### Requirement: 核对投影的完整证据
系统 MUST 在使用者打开投影条目的证据详情时，以**收支详情**呈现净额、经济类型、交易对方、发生时间、账户、分类、备注和来源，使使用者无需理解底层投影结构即可核对该笔收支。仅由两条或更多账本记录、或已确认关系形成的投影条目 MUST 显示「关系投影」；仅由一条账本记录直接形成且未采用已确认关系的条目 MUST 不显示来源标签或成员数量。

系统 MUST 仅在会影响当前结果的同笔支付、退款或其他已采用关系存在时展示**关联记录**，并以业务语义说明其与结果的关系。每条关联记录 MUST 以标签和值的字段列表展示关联类型、金额、发生时间、账户、交易对方、分类、备注、来源和业务影响，不得将这些字段拼接为单行文字。没有关联记录时，界面 MUST 不显示关联记录区域或空态说明。收支详情界面 MUST NOT 显示审计信息、投影标识、来源行快照、业务行标识、关系规则、决策证据、未生效关系提示、完整成员列表或退款时间线；完整的只读追溯数据继续由证据接口提供，且不改变收支投影结果。**优先级理由**：日常核对需要同时看清收支结果、导入渠道和实际关联，而非暴露底层结构。

#### Scenario: 查看单源收支详情
- **WHEN** 使用者打开仅含一条账本记录且未采用已确认关系的投影条目
- **THEN** 收支详情显示该笔收支的金额、交易对方、时间、账户、分类、备注和来源
- **AND** 不显示「单源投影」、「1 条账本记录」或关联记录区域

#### Scenario: 查看关系形成的收支详情
- **WHEN** 使用者打开由同笔支付、退款或其他已确认关系形成的投影条目
- **THEN** 收支详情显示「关系投影」和全部成员来源的去重集合
- **AND** 关联记录以字段列表展示其自身来源和业务影响
- **AND** 不显示审计信息、规则标识或来源快照
