## Why

收支账本目前不能直接看出条目来自哪些导入渠道，关系投影也无法在日常核对时辨别涉及的来源。关联记录把多个字段拼在一行，不利于逐项查看。

## What Changes

- 在收支账本表格增加「来源」列。
- 单源投影显示自身来源；关系投影显示全部成员记录的去重来源，并保留「关系投影」标记。
- 在收支详情增加「来源」字段，使用与投影类型匹配的来源集合。
- 将每条关联记录改为标签和值组成的字段列表，而非将多项信息拼接为一行。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `020-cash-ledger-browser-web`: 收支账本和收支详情展示投影条目及关联记录的导入渠道。

## Impact

- 影响收支列表 API、收支详情抽屉、关联记录样式及相应后端与 Web 测试和视觉快照。
- 列表 API 新增兼容字段 `source_types`，在同一投影快照内提供成员记录来源的有序去重集合；不改变证据接口、收支投影计算、关系匹配、账本记录或持久化。
- 这是 A 类接口合同变更，必须在 SQLite 与真实 PostgreSQL 上验证；可通过还原本次 API、前端与测试改动回滚。
