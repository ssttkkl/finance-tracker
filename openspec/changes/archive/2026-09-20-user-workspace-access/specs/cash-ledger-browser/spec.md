## MODIFIED Requirements

### Requirement: 收支账本展示关系处理后的投影
系统 MUST 让每条活动现金流水恰好归属一个收支投影。没有生效关系的流水形成单源投影；同笔支付只展示一次；退款冲销原消费；内部转账显示但不计入收入、支出和月度汇总；全额退款和余额校准投影保留但不出现在列表中。Web API MUST 只为当前已登录成员的选定工作区返回投影。

#### Scenario: 浏览同笔支付
- **WHEN** 当前成员工作区的两条现金流水通过已确认 `payment_mirror` 表示同一笔消费
- **THEN** 收支账本 MUST 只显示一个消费投影，并在证据详情中展示相关记录

#### Scenario: 浏览银证转账
- **WHEN** 当前成员工作区的收支投影对应已确认现金—投资资金调拨关系
- **THEN** 列表和详情 MUST 显示“银证转账”及其现金与投资账户两端金额，且不得计入外部收支
