## ADDED Requirements

### Requirement: Web 本地现金流水在后台派生

Compose Wasm MUST 从当前使用者和工作区的已提交快照，在浏览器后台派生现金流水列表、筛选、分页及月度汇总，保持原币种、精度、时区和读版本。无需联网即可读取本地账本。

#### Scenario: 本地打开或筛选现金流水

- **WHEN** Web 使用者浏览本地现金流水、翻页或改变筛选条件
- **THEN** 客户端 MUST 使用同一提交版本的列表和汇总，并保持原分页和筛选含义

#### Scenario: 流水后台处理失败

- **WHEN** Worker 不能启动或中途终止
- **THEN** 客户端 MUST 保留当前可见内容，初次打开时显示现有错误入口，并允许在同一工作区使用现有入口重试；不得在页面线程重算
- **AND** 新查询未完成时，保留的结果仅供查看，依赖新查询的选择和批量操作须等到新结果可用
- **AND** 工作区退出、访问失效或已切换仍须执行原隔离规则
