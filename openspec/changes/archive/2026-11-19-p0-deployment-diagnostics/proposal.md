## Why

登录可能在后端已返回成功后因浏览器无法初始化本地账本而中断。部署排查需要辨认构建版本、后端处理结果和浏览器运行条件。

## What Changes

- 后端输出可搜索的访问和异常日志，以服务端生成的请求 ID 关联响应与日志。
- Web 生产构建标识版本。浏览器记录启动能力、全局错误和认证接口响应，以区分服务端错误与浏览器运行故障。
- 用户选定在本地生产构建上验证登录和账本加载。复制入口暂缓。本次范围为本地诊断和标准输出。Sentry、分布式追踪和线上合成监控留在后续阶段。
- 验收覆盖请求 ID 跨源可读、意外异常安全响应、脱敏日志、Web 上报钩子旁路及真实浏览器主流程。

## Capabilities

### New Capabilities

- `shared/deployment-diagnostics`：服务端请求关联及浏览器本地诊断。

### Modified Capabilities

无。

## 影响

Ktor HTTP 层、Compose Web 启动与浏览器 HTTP 层、构建和运维文档。日志从托管环境标准输出读取。回滚应用版本即可撤回新增诊断，浏览器诊断记录规模有上限。
