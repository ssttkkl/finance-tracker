## ADDED Requirements

### Requirement: 可配置的脱敏错误上报

后端与 Wasm Web MUST 在各自配置接收方时只上报允许列事件。后端上报未预期异常，Wasm Web 上报启动与运行故障、认证 5xx 和无 HTTP 状态的认证未知失败。若可用，事件 MUST 关联构建版本及该次认证或 HTTP 调用的请求 ID。采集 MUST 排除原始异常消息、原始 URL、用户标识、凭据、请求内容、账本数据、回放和性能追踪。

#### Scenario: 配置接收方后发生故障

- **WHEN** 后端发生未预期异常或 Web 发生适用错误
- **THEN** 接收方得到固定类型及安全字段的事件，应用同时保留本地诊断

#### Scenario: 未配置或上报失败

- **WHEN** 接收方未配置或不可达
- **THEN** 应用保持原请求与浏览器流程
