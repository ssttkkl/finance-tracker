## Context

问题与验收见 [proposal](proposal.md)。现行 [会话规格](../../../specs/import/cash-import-session/spec.md) 已定义追加合并，客户端也按最多三并发实现。独立检查确认运行 jar 与当前编译类相同；失败来自服务端两次严格修订校验，并非旧包或解析错误。

## Goals / Non-Goals

目标是在现有 Application Service、工作区锁、ParsedImportStore CAS 边界恢复合同，解析留在锁外，每次新上传最多解析一次。追加成功保留最新文件与有效账户／行选择，失效旧计划。非目标包括串行化客户端、自动重试业务确认、改变财务数据、关系规则、schema、账户模型、页面或文案。

## Decisions

追加读取仅拒绝未来修订；取消、过期、归属、权限及永久收据继续阻止追加。合并按 `client_file_ref` 和现有内容摘要判定，同摘要返回当前结果，异摘要拒绝；容量只计算实际新增文件。暂存写入使用刚读取的修订，明确 CAS 冲突才有限重读。重试重新验证权限、收据和最新集合，不重解析，不吞掉存储未知结果或其他异常。合并判定在文件准备辅助内复用，HTTP 的锁外解析／锁内发布保持不变；低层 store 不放宽 CAS。拒绝通过调整客户端并发或全局严格修订校验绕过问题。

真实文件的工行借记卡来源含 CNY／USD；保留目标账户初始只有 CNY 的浏览器场景，验证既有批量补币种路径。该接口沿用 [既有设计](../2026-11-04-reduce-cash-import-account-round-trips/design.md) 和当前账户规格：64 KiB 严格 JSON、1–100 项、全部项目先校验、重复账户／键整体拒绝；每项调用普通账户命令的同一事务与收据机制，在修订校验后将必需币种并入当前集合，不修改其他字段。请求级授权／协议错误整体拒绝，业务冲突逐项返回，前项已成功不回滚；明确存储未知结果以原键核实，程序错误停止而不伪装为项目失败。不得在服务外先 GET 后 PATCH 拼并集，也不新增批量事务或收据。恢复路由及 OpenAPI 接线，不新建领域模型或改变现有命令身份。

共享客户端恒定提交 `timezone_name`，Kotlin 严格协议原先漏收；构建器已保存 `monthly_source`，但公开视图漏算月度汇总。恢复原纯呈现计算及预览／读取接线：默认 UTC、合法 IANA 时区、按完整输入的 all／pending／confirmed 分组；有日期但无统计资格的月份仍保留空币种列表，收入／支出与退款净抵减沿已有 economic_type，Decimal precision 80。时区不进入来源事实或业务规划输入，只影响公开视图；只读投影缓存键包含时区，无效时区在发布前拒绝，保留旧计划。缺少完整月度来源／展示分类的旧计划在读取和提交时返回 plan_changed，原命令核实返回 not_committed；允许以旧计划身份重新预览重建。独立字面量期望与两库 HTTP 请求覆盖此合同，不通过删除客户端字段规避。

夹具从已批准的身份脱敏 JSON 重新生成实际格式，原容器、隐藏元数据和映射均不进入仓库。保留日期、金额、币种、原生枚举、付款组成和行间关系。选择 2026 年 5 月，五个真实来源、11 文件、759 行；工银亚洲没有真实样本，仍由既有合成 reader 测试覆盖。独立期望由匿名单元、Decimal 和现行冻结合同推导，不调用被测解析／归一／规划器；377 条事实保留发生次数，不能用金额时间三元组去重，也不能用投影数量代替事实数量。

## Risks / Trade-offs

并发 CAS 耗尽仍明确返回修订冲突；有限重试防止无限资源消耗。幂等重复不改变修订、有效期或文件结果。并发与关闭／提交竞争必须由工作区锁和永久收据共同约束。SQLite 与 PostgreSQL 复用同一测试场景，测试库显式配置并以 `_test` 结尾；测试不自行启动或探测数据库。

原日期和金额可反映真实财务活动，这是用户明确选择的部分脱敏边界，不能标为全合成。独立复核覆盖身份残留、原容器元数据、财务单元及原文件哈希不变。生成器仅接受已脱敏 JSON，使用现有 POI／PDFBox 依赖，不接触原件。工作簿时间戳可变化，重建验证以解码内容和结构为准，manifest 始终校验实际提交字节。

## Migration Plan

无数据迁移。先运行失败回归，再最小修复及双库完整后端、真实浏览器流程、现有 CI。Web、Native 与共享 UI 合同不变；真实浏览器保留四文件一次选择以验证三并发，Android／iOS 不新增交互 QA。完成独立范围与契约审查、文档、反思和归档后按既有授权更新 PR；不执行合并或部署。回滚本次实现与测试提交即可。
