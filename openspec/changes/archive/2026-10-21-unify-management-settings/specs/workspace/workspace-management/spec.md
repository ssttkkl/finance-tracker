## MODIFIED Requirements

### Requirement: 工作区管理作为一级页面提供管理任务

系统 MUST 在统一侧边导航中提供与收支账本、投资账本同级的“管理”入口。页面标题 MUST 为“管理”，不得使用当前工作区名称替代页面标题，也不得提供重复的页面内账本返回入口。独立的收支分类导航 MUST 合并到管理页内；既有 `/workspace-management` 地址 MUST 继续可访问。

#### Scenario: 成员从侧边导航打开工作区管理

- **WHEN** 已登录成员点击“管理”
- **THEN** 系统 MUST 在统一右侧内容区打开管理页面，并且侧边导航只标记该一级入口为当前项

#### Scenario: 页面不重复提供账本导航

- **WHEN** 管理页面加载完成
- **THEN** 页面 MUST 不显示“返回账本”链接或常驻功能介绍、操作影响说明

#### Scenario: 旧工作区管理链接仍有效

- **WHEN** 使用者打开当前工作区的 `/workspace-management` 链接
- **THEN** 系统 MUST 打开标题为“管理”的统一页面，保留当前工作区和既有浏览器历史行为

### Requirement: 成员与邀请按管理任务纵向组织

管理页面 MUST 在同一内容区以两级结构纵向展示管理任务：一级“工作区资料”下包含二级“基本信息、危险操作”，一级“访问权限”下包含二级“成员与权限、邀请成员”，一级“收支账本”下包含二级“收支分类”。一级、二级 MUST 有可区分的可见标题；一级之间 MUST 有明确分隔。尚无实际配置的投资账本 MUST 不展示占位分组。管理员 MUST 能调整其他成员角色、移除成员并创建指定角色的邀请链接；非管理员 MUST 只能查看成员和当前工作区信息，不能执行这些写操作。收支分类 MUST 继续遵守自身的编辑者可写、查看者只读权限。危险操作 MUST 仅向管理员展示，且只包含本次已有的删除工作区能力。

#### Scenario: 配置按管理领域分为两级

- **WHEN** 管理员打开管理页面
- **THEN** 正文 MUST 依次呈现工作区资料、访问权限、收支账本三个一级分组，二级配置 MUST 按上述归属和顺序排列
- **AND** 页面及目录 MUST 不显示投资账本空入口

#### Scenario: 管理员管理成员和创建邀请

- **WHEN** 管理员在页面调整成员角色、移除成员或选择“可编辑/仅可查看”后点击“创建链接”
- **THEN** 系统 MUST 调用既有成员/邀请行为并在页面显示对应结果，邀请角色以创建时选择为准

#### Scenario: 非管理员访问工作区管理页面

- **WHEN** `editor` 或 `viewer` 打开管理页面
- **THEN** 页面 MUST 保留工作区、成员和邀请的信息结构，但名称、角色、移除和创建邀请控件 MUST 不可写入
- **AND** `editor` MUST 可维护收支分类，`viewer` MUST 只读，危险操作及其目录项 MUST 不可见

#### Scenario: 分组失败彼此隔离

- **WHEN** 分类读取失败但工作区读取成功，或工作区读取失败但分类读取成功
- **THEN** 系统 MUST 在失败分组提供错误和重试，并保留另一部分的可用内容与操作

### Requirement: 工作区管理页面适配桌面与移动视口

页面 MUST 在统一账本壳内使用一个管理正文滚动区，并在 `compact` 下改为单列布局。`regular` / `wide` MUST 在正文右侧显示管理目录，目录不得随正文离开视口；`compact` MUST 在工具栏右上角显示目录按钮，并使用全屏对话框呈现相同的目录条目。页面在 320、375、390、414、768 和 1440 px 宽度下 MUST 不产生横向滚动或文本溢出。

#### Scenario: 桌面端按顺序使用可用内容宽度

- **WHEN** 使用 1440 px 宽度打开管理页面
- **THEN** 三个一级管理分组及各自二级配置 MUST 按顺序从上到下排列，正文独立滚动，右侧两级目录持续可用

#### Scenario: 移动端使用单列布局

- **WHEN** 使用 390 px 宽度打开管理页面
- **THEN** 所有分组 MUST 单列排列，页面 MUST 无横向滚动且所有主要操作可触达
- **AND** 工具栏目录按钮 MUST 可打开全屏管理目录

## ADDED Requirements

### Requirement: 管理目录提供同页定位并跟随正文滚动

管理目录 MUST 与当前角色可见分组保持相同的两级归属、顺序、名称和可用性；右侧目录与全屏目录 MUST 使用相同条目，二级项 MUST 缩进。选择一级分组 MUST 定位其一级标题和首个可见二级配置；选择二级配置 MUST 定位该配置正文。定位 MUST 在当前管理页滚动，不得切换成另一份分组页面或丢弃已有表单内容。当前二级项 MUST 随正文滚动更新，通过可访问状态和可见标记表达，不得仅靠颜色区分；所属一级分组 MUST 有辅助强调，但不得暴露第二个当前二级项。

#### Scenario: 从目录定位一级领域

- **WHEN** 使用者选择一级“访问权限”
- **THEN** 正文 MUST 定位访问权限标题及成员与权限配置，保留当前表单和搜索状态

#### Scenario: 非管理员目录隐藏危险操作

- **WHEN** 非管理员打开任一形态目录
- **THEN** 目录 MUST 隐藏危险操作，但仍显示工作区资料及其基本信息子项

#### Scenario: 从右侧目录定位分类

- **WHEN** `regular` / `wide` 使用者选择“收支分类”
- **THEN** 正文 MUST 定位到分类分组且目录将其标记为当前项

#### Scenario: 从手机目录选择分组

- **WHEN** `compact` 使用者打开目录并选择“成员与权限”
- **THEN** 全屏目录 MUST 关闭，原正文 MUST 定位到该分组并提供可识别的焦点位置

#### Scenario: 取消手机目录

- **WHEN** 使用者通过关闭按钮、系统返回或 Escape 取消全屏目录
- **THEN** 系统 MUST 保留原正文滚动位置和草稿，并将焦点恢复到目录按钮

#### Scenario: 手动滚动并切换窗口等级

- **WHEN** 使用者手动滚动正文或在 `compact`、`regular`、`wide` 间切换
- **THEN** 目录 MUST 反映当前正文分组，且不得丢失当前工作区、分类搜索或未提交草稿
