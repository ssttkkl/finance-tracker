## Why

工作区资料、成员与邀请集中在工作区管理页，而收支分类另占一个导航入口。将现有管理任务集中到可定位的分组长页，形成后续管理能力的统一入口。

## What Changes

- 一级入口和页面标题统一为“管理”，移除独立的分类导航项。
- 按两级组织现有功能：工作区资料下为基本信息、危险操作；访问权限下为成员与权限、邀请成员；收支账本下为收支分类。正文与两种目录均表达相同层级，以 M3 文字角色、平面分组、细分隔和一致对齐呈现；局部操作按内容测量。
- `regular` / `wide` 显示固定右侧管理目录；`compact` 工具栏右上角的目录按钮打开全屏目录。两种形态共用条目，选择后定位正文，滚动更新当前项。
- 收支分类列表内嵌；新增和编辑在 `compact` 全屏模态、`regular` / `wide` 对话框完成，结束后保留分类列表上下文。
- 保留 `/workspace-management`；旧 `/cash-categories` 链接打开统一管理页并定位收支分类，浏览器历史与工作区切换仍有效。
- 不新增账户管理、投资写入、同步或数据维护能力，不改金额、权限、持久化与 API 合同。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `workspace/workspace-management`：统一管理入口、分组、目录和三种窗口布局。
- `cash-ledger/cash-category-management`：分类内嵌承载、模态编辑和旧链接兼容。

## Impact

- Compose `commonMain` 的导航、管理页、分类呈现、语义 ID 和文案；共享 Web、Android、iOS。
- 对应 Kotlin 测试、Compose Web Playwright、功能地图和词表；旧 React / Expo 不在本次范围内。
- 采用 A 类强度：涉及导航与跨端 UI 合同。没有数据库、后端或依赖变更；回滚为恢复客户端旧入口及页面组合。
- 2026-10-21 已通过 `grill-me` / `grilling` 三轮澄清：用户确认本次仅迁入已有工作区管理和收支分类、统一命名、移除分类独立入口、同页目录、手机全屏目录及模态分类编辑。
- 用户已明确要求按当前分支最新约束执行：记录信息架构和 Hallmark 设计方向后直接实现共享 Compose；不产出 HTML 原型，最终以 Compose 演示及 QA 验收。
- 用户在排版演示后确认以上两级归属、两级同页目录和危险操作位置；投资账本在具备实际配置后再加入，本次不增加占位入口。
