## ADDED Requirements

### Requirement: 单一原子组成项应用已确认账户映射

账单业务行只有一个原子资金组成项时，系统 MUST 将已确认的来源账户映射应用到父业务行及其组成项的账户引用。组成项 MUST 使用映射目标的账户 ID 和名称，同时保留来源账户键、来源标签、精确金额及原始来源行快照。

#### Scenario: 来源账户标签与映射账户名称不同

- **WHEN** 一条账单业务行只有一个原子资金组成项，且使用者把来源账户映射到名称不同的既有账户
- **THEN** 预览中的父业务行和组成项 MUST 指向所选目标账户
- **AND** 组成项 MUST 保留原来源账户键与来源标签、原精确金额及原始来源行快照
- **AND** 最终确认 MUST 按同一目标账户持久化父业务行和组成项
