## Why

现金导入和流水查询已共用浏览器计算产物，但各入口重复处理等待、取消和通讯错误。现有 Worker 根据消息字段形状猜测任务，增加任务时要同步维护两套判定。

## What Changes

统一 Web 计算 Worker 的消息协议、派发、请求生命周期及 Kotlin 等待封装。现有导入和流水查询全部经统一入口，保留导入任务复用实例和流水会话持有实例的策略。

## Capabilities

内部实现调整。导入流程、记账精度、账本查询、权限、错误恢复、存储及 HTTP 合同均按现有规格。

## Impact

划为 B 类。影响同一个 Web 计算 Worker 产物及其调用方，启动、取消和回包关联需真实浏览器验证。回滚可恢复上一版 Web 产物。
