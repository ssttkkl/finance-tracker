## Context

导入 Worker 槽按任务借用并保留一个空闲实例。流水查询 Worker 由已认证的账本会话持有并保留当前版本索引。二者共用计算入口及 Wasm 发布产物。SQLite 的连接、租约与密钥由独立存储 Worker 管理。

## Decisions

- 计算调用统一发送 `requestId`、`operation` 和 `payload`。入口按已注册的命令派发，回包携带同一请求编号。连接一次接收一个任务，忽略已完成任务的迟到回包并拒绝非法回包。
- Kotlin/Wasm 共用挂起等待及取消桥接，对业务保留具名方法及类型化结果。连接处理就绪、关闭及通讯故障。各调用方继续区分单文件重试、流水重试、确认前失败和确认后恢复。
- 导入复用策略、流水会话及快照版本围栏、离线预热、SQLite 通讯、发布路径和业务数据格式沿用现有合同。本次保留既有并发策略。原生端及 Kotlin/JS 使用原平台实现。

## Risks

取消当前计算会终止它所在的 Worker。回归应验证取消旧请求不影响新任务，两个实例的故障互相隔离，且流水离线重建只读取当前账本。使用既有内容指纹同时发布客户端和对应入口，回滚恢复上一版 Web 产物。
