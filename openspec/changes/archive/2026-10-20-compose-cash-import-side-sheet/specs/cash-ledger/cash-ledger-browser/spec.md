## MODIFIED Requirements

### Requirement: 收支账本导入使用独立四步处理页面

收支账本 MUST 仅从账本内的「导入账单」操作打开账单导入二级页面；账单导入 MUST NOT 作为全局侧栏一级目的地。二级页面 MUST 使用统一容器：横向 `WindowSizeClass` 为 `REGULAR` 时，以贴右、全高且宽度占当前视口 90% 的模态侧边面板承载；为 `WIDE` 时，占 70%；`COMPACT` 以全屏页面承载。导入流程 MUST 保留「选择文件」「映射账户」「核对流水」「关系配对」四步，明确当前步骤、可返回的上一步和最终确认导入入口。容器关闭或返回 MUST 回到收支账本，并丢弃尚未确认的临时导入会话。

核对步骤 MUST 直接显示流水筛选和流水列表，不在标题下重复显示流水总数。关系配对步骤 MUST 直接显示筛选器和配对列表，不显示配对说明或筛选器上方的自动匹配/待确认汇总；筛选器本身仍 MUST 显示结果计数。每条待确认配对 MUST 使用一个始终可见、可通过鼠标和键盘选择的下拉框：未选择时显示「选择流水」占位项，已有候选项在同一下拉框中选择；不得把待选状态、说明和另一个「选择流水」按钮分散重复展示。选择候选后 MUST 在同一行保留所选流水，并同步配对状态与筛选计数。

#### Scenario: 从收支账本打开账单导入

- **WHEN** 使用者点击收支账本中的「导入账单」
- **THEN** 页面 MUST 打开账单导入二级页面
- **AND** 全局侧栏 MUST 不显示账单导入目的地
- **AND** 现有直接导入 URL MUST 打开同一二级页面

#### Scenario: 在 regular 窗口查看导入

- **WHEN** 使用者在横向 `WindowSizeClass` 为 `REGULAR` 的窗口打开账单导入
- **THEN** 导入 MUST 显示为贴右、全高且宽度占当前视口 90% 的模态侧边面板
- **AND** 标题栏 MUST 提供可访问的关闭按钮，所有底部步骤操作 MUST 保留
- **AND** 侧边面板打开期间，账本和导航背景 MUST 被遮罩且不可交互
- **AND** 关闭按钮或键盘 Escape MUST 关闭面板并返回账本

#### Scenario: 在 wide 窗口查看导入

- **WHEN** 使用者在横向 `WindowSizeClass` 为 `WIDE` 的窗口打开账单导入
- **THEN** 导入 MUST 显示为贴右、全高且宽度占当前视口 70% 的模态侧边面板
- **AND** 标题栏 MUST 提供可访问的关闭按钮，所有底部步骤操作 MUST 保留
- **AND** 侧边面板打开期间，账本和导航背景 MUST 被遮罩且不可交互
- **AND** 关闭按钮或键盘 Escape MUST 关闭面板并返回账本

#### Scenario: 在 compact 窗口查看导入

- **WHEN** 使用者在 `COMPACT` 窗口打开账单导入
- **THEN** 导入 MUST 覆盖当前窗口显示为全屏页面
- **AND** 页面左上方 MUST 提供有无障碍名称的返回按钮及唯一页面标题
- **AND** 返回 MUST 回到收支账本，且返回按钮 MUST 使用 Material 3 默认图标按钮尺寸与触控目标

#### Scenario: 在步骤间返回

- **WHEN** 使用者从账户映射、流水核对或关系配对返回上一步
- **THEN** 页面 MUST 保留仍然有效的文件、扫描结果、映射选择和预览结果
- **AND** 返回后修改文件或账户映射时 MUST 清除所有受影响的后续步骤状态

#### Scenario: 选择文件步骤继续

- **WHEN** 使用者在选择文件步骤已经选中文件
- **THEN** 底部主操作 MUST 显示为「下一步」，文件选择控件仍 MUST 是唯一的选文件入口
- **AND** 无密码文件扫描成功后 MUST 自动进入账户映射步骤
- **AND** 需要密码的文件 MUST 停留在当前步骤，点击「下一步」时才提交密码并继续扫描
- **AND** 从账户映射返回后点击「下一步」MUST 复用保留的扫描结果，不得重复扫描
- **AND** 本地识别为受保护的 PDF 时 MUST 在开始服务端扫描前显示密码输入

#### Scenario: 离开未确认的导入

- **WHEN** 使用者在最终确认导入前关闭或离开导入二级页面
- **THEN** 页面 MUST 丢弃本次未确认的文件、账户映射和关系决定并返回收支账本
- **AND** MUST NOT 在数据库中留下新账户、账户支持币种、账单账户映射、账本记录、关系、余额或投影变化

#### Scenario: 查看大量关系建议

- **WHEN** 导入会话产生数百或数千条自动配对或待手动配对建议
- **THEN** 关系列表 MUST 连续展示筛选结果，不得要求使用者切换分页
- **AND** 窄屏 MUST 使用可纵向浏览的配对卡片且不得出现列表内横向滚动

#### Scenario: 用下拉框确认待配对流水

- **WHEN** 使用者查看尚未配对的导入流水
- **THEN** 对应行 MUST 直接显示唯一的「选择流水」下拉框和可选的已有流水
- **AND** 鼠标或键盘选择候选流水后，当前行 MUST 显示所选内容，待确认与已匹配筛选计数 MUST 随之更新
- **AND** 核对步骤 MUST 不显示标题下的流水总数；关系配对步骤 MUST 不显示说明段落或筛选器上方的配对汇总

#### Scenario: 关闭导入侧板后焦点返回入口

- **WHEN** 使用者关闭 `REGULAR` 或 `WIDE` 导入侧板
- **THEN** 页面 MUST 返回收支账本
- **AND** 键盘焦点 MUST 返回「导入账单」入口
