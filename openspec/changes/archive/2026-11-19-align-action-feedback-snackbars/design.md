## 范围与呈现

B 类。跨端共用 Compose，影响限于几组局部反馈及浏览器剪贴板适配，保留现有路由和业务端口。没有重新设计页面。管理正文、账本操作区和导入子任务负责各自反馈。去掉管理页顶部复制和改名成功提示、生成链接后的重复成功提示、账号面板切换成功文字、可以从原处恢复的单确认错误弹窗。

| 场景 | 验收 |
| --- | --- |
| 管理页复制 ID 或邀请链接 | 显示一次结果。Clipboard API 不可用和拒绝均反馈失败。连续同样操作不会积压提示。 |
| 成功改名、创建邀请、切换工作区 | 改名结果播报一次。链接或当前工作区直接展示另两项的结果。 |
| 导入处理详情、导入任务或账户表单请求中尝试退出 | 在当前层显示一条等待消息。保留任务和原请求，完成后旧消息消失。 |
| 分类或账本删除影响读取失败 | 已识别的临时失败提示重试，保留原对象及入口。权限、事实变化及程序错误保留可持续查看的反馈。 |
| 确认后异步结果 | 当前弹窗保留内联错误。关闭后已知且可从原处处理的失败短暂显示，其余在任务内持续显示并连接现有只读恢复。 |

## 实现与风险

沿用 Material 3 Snackbar Overview、Specs 和 Compose SnackbarHost API。使用默认 Snackbar 与主题，Host 随任务层销毁。新消息取代旧消息，重复消息不排队，取消通知不取消业务请求。布局按现有安全区、键盘和操作栏避让。验收检查焦点、可见性和辅助技术播报。采用项目现有语义、token 和任务结构，避免常驻成功反馈和额外确认。

用原读取／写入结果区分显示，保留取消传播和诊断。只读失败可从原处重试。对事实变化从原区域刷新，结果无法确定时读取当前事实，不主动重放提交。保留当前有原身份和收据的核实合同。账本与分类复用在线账本同步，读取旧缓存不算完成核对。工作区通过只读会话与当前详情核对，操作入口在本地会话暂未恢复时仍可用。删除确认绑定原目标与版本。无接口或持久化变更。回滚为撤回同组共享代码、Web 适配与规格。
