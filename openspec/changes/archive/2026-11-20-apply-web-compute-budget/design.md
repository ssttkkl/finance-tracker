## Context

采用项目上下文中的 P95 50 毫秒门槛。选择已验证的实际入口和相同合成样本。

## Goals / Non-Goals

将大计算移出页面线程并消除重复编解码。沿用已有结果页面、用户操作和业务规则。

## Decisions

流水详情、证据、目录及定位与列表共享版本化 Worker。快照使用原缓存所有者校验与写入，冷读和在线更新的完整校验交给 Worker。导入从冻结材料计算并仅交付所需字段和当页结果，文件级失败沿原入口恢复。Worker 将冻结写集封装为 Blob，Web 发出请求前再次核对会话代次，保留原正文和幂等键。持仓沿现有视觉和交互使用惰性行列表及稳定计算输入。

## Risks / Trade-offs

Worker 更新不得残留旧工作区或已撤销快照。大请求桥改动需要验证原正文、取消、HTTP 错误和不同响应体。回滚为恢复上一版客户端。
