## ADDED Requirements

### Requirement: 首次工作区名称按登录名和界面语言预填

用户进入首次创建工作区页面时，客户端 MUST 在可编辑字段中预填按当前界面语言表达的工作区名称。登录名使用登录邮箱中 `@` 前的部分，中文模板为“{登录名} 的工作区”。预填只提供名称建议，用户须主动点击创建。

#### Scenario: 注册后直接创建或编辑默认名称

- **WHEN** 注册成功且当前账号尚未加入工作区
- **THEN** 首次创建页 MUST 展示符合名称校验的已填名称。用户可以直接提交、修改或清空。重新布局、连接状态变化和创建失败 MUST 保留用户已编辑的内容。未编辑时随界面语言显示对应模板。
