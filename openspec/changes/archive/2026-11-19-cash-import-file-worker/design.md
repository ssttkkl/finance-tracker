## Context

浏览器已具备同源导入 Worker 及离线资源缓存。账单文件读取和格式处理目前在页面执行。现有文件捕获保存规范化文档、摘要和原始字节，已知失败保存元数据。

## Goals / Non-Goals

迁移 Web 文件处理，维持原格式、字节上限、精度、缓存格式、会话所有权及在线解析。原生调度照旧。后续预览分页协议独立实施。

## Decisions

复用导入 Worker 的就绪、取消与重建机制。CSV／XLSX 扩展名的入口结构化克隆浏览器 File，仅 Worker 有界读取，字节识别后转远端时传回原有界缓冲区。PDF／旧 XLS 扩展名沿用现有读取入口。远端解析由原身份调用 API。页面与 Worker 共用解析和序列化规则，禁止重新推定来源。失败在文件读取和 Worker 边界映射到单文件结果，错误和原选择沿既有控件呈现。

## Risks / Trade-offs

保存和恢复仍按原缓存格式及完整性验证；主线程仍可能执行缓存重读和账户准备。测量选文件至账户准备的长任务，并验证原结果、混合批次、取消、离线和远程分流。
