## Context

计算已移至 Web Worker。当前页面仍一次性接收完整计划、读模型、核对上下文和写集，再在页面构造查询读取器。

## Goals / Non-Goals

首次使用既有摘要与首屏模型，后续按实际阅读需求取数据。保留现有财务规则、页定位、关联候选、时区与确认语义；原生继续用本地读取器。

## Decisions

Web Worker 将已验证的完整计划、分页数据及提交材料放入 SharedArrayBuffer 内存分区。首次响应仅解码现有摘要、首屏和须写入加密批次的核对记录。页面持有同一次核对的共享内存分区引用，后续请求由现有 Worker 池读取所需分区；Worker 重建仍可重读同一分区。分页、详情和处理明细沿用原读取器。提交材料仅在明确确认后解码并交给原冻结入口。月度统计与页面共用浏览器时区算法。Worker 在发布前写完内存分区，客户端仅读取。继续使用账本 Web 缓存已有的跨源隔离条件，避免浏览器 Blob 配额触发明文落盘。

## Risks / Trade-offs

Worker 重建后可重读同一内存分区；分页通讯暂时失败时沿用现有分页重试，不能读取确认材料时不写入，并提供重新核对。已冻结提交沿原幂等键继续恢复。主线程仍需编码请求与读写本地加密缓存。用合成大账单比较回包大小、关键帧及业务结果。
