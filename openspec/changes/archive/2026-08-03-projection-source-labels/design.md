# 设计：收支投影来源标识

## 决策

投影条目分为两个面向使用者的名词：

- **单源投影**：`composition` 为空且 `member_count` 为 `1`，表示一条账本记录直接形成结果。
- **关系投影**：其他情况，表示已确认关系参与结果形成；主列表显示成员数，具体成员和关系仍在证据详情核对。

该判断只读取服务端随投影返回的 `composition` 和 `member_count`，不由前端根据交易对方、金额或备注猜测。

## 界面策略

在主列表「交易信息」单元格的备注之后加入紧凑、可读的来源标签。标签使用文字、成员数和可访问名称，而不是仅依赖颜色；窄屏继续随该单元格纵向排列。证据详情的「投影结果」区域显示相同结论，作为打开详情后首先可见的审计上下文。

## 风险与回滚

异常或旧响应缺少预期数组时以单源投影处理，只影响标签呈现，不影响金额、列表排序或证据读取。回滚仅移除前端标签与相应文案，无需数据回滚。

## UI 审计策略

本变更复用现有高密度收支账本设计系统，不引入新页面、路由或交互。完成后审查桌面和窄屏下标签的可读性、焦点样式、色彩对比和文本溢出。
