## MODIFIED Requirements

### Requirement: 受支持账单直接进入统一导入流程

受支持的 CSV、XLS、XLSX 和 PDF 账单 MUST 先经过临时导入会话中的解析、验证和账户路由确认，再在最终确认边界写入当前运行时数据库。原始文件和临时预览只能作为短期输入证据，不得成为运行时账本、迁移载体或数据库不可用时的回退。

#### Scenario: 导入受支持文件

- **WHEN** 使用者为当前工作区提交格式有效的受支持账单并完成账户映射、流水核对和关系确认
- **THEN** 系统 MUST 从临时来源读取有效业务行，在一个最终事务中转换并写入当前工作区账本记录，并返回可核对的导入计数

#### Scenario: 预览不写账本

- **WHEN** 使用者只完成文件扫描、账户映射确认或流水预览
- **THEN** 系统 MUST 返回可核对的扫描或预览结果，但不得写入账户、账户币种、账单账户映射、现金流水、交易关系或收支投影

### Requirement: 导入失败不泄露敏感来源数据

解密、解析、映射、精度、币种、时间、临时存储或持久化错误 MUST 使导入失败关闭，错误信息不得记录账单密码、完整账号、原始账单正文、完整 `import_token` 或整行来源数据；临时对象 MUST 按会话清理策略删除或过期。

#### Scenario: 加密 PDF 密码错误

- **WHEN** 使用者提供的 PDF 密码无法解密账单
- **THEN** 系统 MUST 返回明确失败且不创建账本记录，日志不得包含密码或账单正文，并允许当前临时会话在有效期内安全重试

#### Scenario: 临时存储不可用

- **WHEN** R2 读取、写入或删除失败
- **THEN** 系统 MUST 返回可识别的临时存储错误，不得写入部分账本记录或把敏感文件回退到未受控的本地路径
