## MODIFIED Requirements

### Requirement: 临时导入会话保存来源但不写入业务账本

系统 MUST 在每次上传请求内解析文件并删除原始输入，不将原文件或用户填写的密码字段值保存至会话；只保存有 TTL 的解析行、当前会话分组数据和本次选择。用户上传的文件名文本按「导入文件名按上传原样展示」保留；其中的密码字样不视为用户填写的密码字段值。一个会话最多 20 份文件，每份最多 100 MB。公开 API 和临时会话 MUST NOT 包含用户填写的 `source_scope_label`。微信和支付宝来源账户可返回本次会话有效的分组引用和显示标签；昵称、脱敏标签、文件名及分组引用不得成为长期身份或持久映射。各渠道已有的稳定来源身份继续依其渠道合同处理；微信不得使用昵称或来源名称建立跨导入映射。预览 MUST 不写流水、来源绑定、映射或关系；账户普通命令独立立即生效。

#### Scenario: 首次上传及删除输入

- **WHEN** 上传受支持账单
- **THEN** 返回绑定操作者和工作区的不透明会话及逐文件结果；再次预览只读解析结果，原文件不能下载或重读

#### Scenario: 独立账户生效

- **WHEN** 在导入内创建或修改账户成功
- **THEN** 该账户立即可查询和选择，退出导入不自动撤销

#### Scenario: 首次提交多份文件创建会话

- **WHEN** 使用者为当前工作区提交一组格式受支持的账单文件进行扫描
- **THEN** 系统 MUST 返回不透明的 `import_token`、批次摘要、按文件返回的摘要与识别状态，以及合并后的来源账户扫描结果
- **AND** Neon 中不得出现本次导入的业务写入

#### Scenario: 部分文件需要密码

- **WHEN** 一组文件中有一个或多个加密账单尚未提供密码
- **THEN** 系统 MUST 在同一会话保留已解析文件的结果，并只把加密文件标记为需要密码；服务端保留有效文件；Compose 文件步骤要求先提交密码重试成功或删除需密码文件，再进入账户映射、预览和一次最终确认
- **AND** 密码文件需由使用者连同当次密码重新上传解析；系统不得保存原文件或用户填写的密码字段值，文件名文本按原样展示规则保留

#### Scenario: 预览引用既有多文件会话

- **WHEN** 使用者提交有效的 `import_token` 和账户映射以请求流水预览
- **THEN** 系统 MUST 从临时会话读取已解析文件中的有效业务行并返回合并预览，保留各文件状态；需要密码的文件只有重新上传后才能加入预览

#### Scenario: 用户来源名称不进入会话

- **WHEN** 用户上传、重传或更新微信文件并读取导入会话
- **THEN** 请求、响应和会话 MUST NOT 提供或保存 `source_scope_label`，也不得提供按文件修改微信来源范围的操作

#### Scenario: 账号分组只在当前会话有效

- **WHEN** 当前会话包含多个微信昵称或支付宝账号的文件
- **THEN** 相同微信昵称或相同支付宝账号的来源资金方式可共用本次分组引用；缺少昵称或账号时按文件分别分组
- **AND** 分组引用、昵称、脱敏显示标签和文件名 MUST NOT 进入来源绑定或跨导入账户映射，且随会话到期；其他渠道可按各自既有合同继续使用可信来源身份

### Requirement: 文件级扫描状态可分别重试且有效文件可继续

文件 MUST 分别返回就绪、部分可用、需密码或失败；可处理文件及可辨认业务行 MUST 不被其他文件问题阻塞。重试需原文件及当次密码，删除或替换文件只改变对应临时解析内容。全部无业务行时只显示文件结果。用户上传的文件名文本按「导入文件名按上传原样展示」进入会话显示名；它不构成密码字段值。

#### Scenario: 某文件无法解析

- **WHEN** 一份文件失败而其他文件有可辨认行
- **THEN** 服务端允许预览并导入其余记录，显示失败原因且不伪造整文件草稿；Compose 文件步骤先要求重试或移除失败文件，见 `import/statement-import`「文件选择步骤允许在上传中追加」

#### Scenario: 单行解析异常

- **WHEN** 可定位的一行解析失败
- **THEN** 该行跳过并返回安全原因，继续处理其他行

#### Scenario: 所有文件扫描完成

- **WHEN** 会话内每个文件都已成功识别并解析
- **THEN** 系统 MUST 返回合并后的来源账户分组并允许进入账户映射

#### Scenario: 部分文件失败仍可继续

- **WHEN** 会话内至少一个文件无法识别渠道或解析失败，且另有文件已就绪或部分可用
- **THEN** 服务端 MUST 返回失败文件的可操作错误并保留已就绪文件；Compose 文件步骤要求先重试成功或移除失败文件，再进入账户映射、预览和一次最终确认
- **AND** 不得为失败文件伪造草稿或业务结果；全部文件均无业务行时只显示文件结果

#### Scenario: 密码只在当前请求使用

- **WHEN** 使用者重新上传一个或多个加密文件并在该次解析请求提交密码
- **THEN** 系统 MUST 按文件将密码仅用于当前受限请求
- **AND** 用户填写的密码字段值 MUST NOT 写入临时会话对象、响应、日志、浏览器持久化或业务数据；文件名文本中的密码字样不视为密码字段值
