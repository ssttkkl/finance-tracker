## Why

合入后的共享流水表格仍有三个可见缺陷：月份分组行没有覆盖金额列，导入状态标签层级过弱，零金额被误当成有方向的收入或支出。它们会降低大量导入流水的扫描效率，也让零金额记录产生错误的视觉语义。

## Scope

- 让月份分组行覆盖共享表格的全部列。
- 提高“待新增 / 已存在”状态标签的对比度、尺寸和语义层级，并补齐其他导入状态的统一样式。
- 将所有精确为零的金额（包括 `0.00`、`-0.00` 等）显示为无符号、默认黑色，并移除方向箭头和方向色。
- 将顶部“全部 / 待新增 / 已存在 / 无法识别”摘要块改为可键盘操作的筛选按钮，只过滤下方预览表格；无匹配时显示空结果提示。
- 不改变导入状态判定、请求合同、账本金额存储或其他表格行为。

## Acceptance

- 月份分组行的 `colSpan` 与当前表格实际列数一致，背景和内容横向铺满。
- “待新增”和“已存在”在桌面和小屏均清晰可辨，并保留文字状态。
- 零金额在收支账本和导入预览中均显示为 `0... 币种`，没有 `+` / `-`、颜色或方向箭头。
- 点击状态摘要按钮只改变下方表格内容，`全部` 可恢复完整列表，按钮具有明确选中状态。
- 受影响单元测试、生产构建和真实浏览器 QA 通过。
