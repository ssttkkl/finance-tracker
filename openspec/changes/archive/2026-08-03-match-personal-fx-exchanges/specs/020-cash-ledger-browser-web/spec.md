## ADDED Requirements

### Requirement: 个人购汇的收支账本展示
系统 MUST 将双边 `accepted transfer_pair(currency_exchange)` 的个人购汇展示为一条可见的个人转账投影，而不是分别展示为消费与收入。该条目 MUST 显示跨币种“转出金额 币种 → 转入金额 币种”，其 `net_amount` MUST 为精确十进制 `0`，并 MUST NOT 计入收入、消费或任何月度收支汇总。两条原始现金流水、来源快照和关系证据 MUST 继续可通过证据详情审计；未确认的 `fx_out` / `fx_in` 不得仅因类型而被隐藏或合并。

#### Scenario: 收支账本显示已确认个人购汇
- **WHEN** 用户读取包含已确认 `fx_out` / `fx_in` 换汇关系的收支账本
- **THEN** 页面 MUST 显示一条“个人转账”及完整跨币种双端金额，不显示其对应的独立消费或收入条目，且月度汇总不包含两端金额

### Requirement: 已采用购汇关系的安全证据详情
系统 MUST 在证据详情中返回已采用购汇关系的字段级白名单证据，以支持审核确认依据。白名单 MUST 支持规则 ID、来源对/状态、时间差或时间精度、候选数与有限候选业务行标识、金额/币种、绑定和阻断原因；`time_delta_seconds` MAY 为 `null`。系统 MUST 对每个字段实施类型、长度和数组上限校验，并 MUST NOT 返回原始来源快照、姓名、账户隐私字段、任意嵌套对象或未知 evidence 键。

#### Scenario: 购汇关系证据可审计且不泄露来源行
- **WHEN** 用户查看已确认个人购汇的证据详情
- **THEN** 页面 MUST 显示允许的关系证据字段及其文字状态，并不得显示未经白名单允许的原始来源字段或隐私数据
