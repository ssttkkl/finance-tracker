## ADDED Requirements

### Requirement: 草稿保存与备注决策提供真实控件语义

草稿编辑的保存按钮、共用备注清空决策的两个选项及确认按钮 MUST 在 Web、Android 和 iOS 向辅助技术表达实际交互角色及选中、禁用状态。两个备注选项 MUST 作为单选提供当前是否选中的状态；没有可保存改动或正在提交时，草稿保存动作 MUST 保持真实不可提交状态并表达禁用。未选择备注处理方式时，确认按钮 MUST 表达禁用。平台适配 MUST 不改变财务请求、身份、精度、幂等或确认语义。

#### Scenario: 备注清空决定
- **WHEN** 使用者在备注清空确认中查看或选择恢复原有备注、保留为空
- **THEN** 两个选项 MUST 向辅助技术表达单选角色与真实选中状态，未选择时确认动作 MUST 表达禁用且不能提交
- **AND** 查看或选择本身 MUST 不产生财务写入

#### Scenario: 刷新后没有改动可保存
- **WHEN** 草稿在明确拒绝后重新读取，且使用者没有修改任何字段
- **THEN** 保存动作 MUST 表达禁用，点击或键盘激活 MUST 不创建新预览、提交或结果核实请求

### Requirement: Web 搜索到筛选保留键盘操作

Web 账本搜索框 MUST 在 Tab 或 Shift+Tab 移到筛选控件时保留后续键盘操作能力；临时输入节点销毁不得中断 Compose 当前逻辑焦点的键盘事件。

#### Scenario: Web 输入框离开后键盘继续操作当前控件
- **WHEN** 用户实际点击搜索框并按 Tab 移到筛选控件，Web 临时输入 DOM 随失焦销毁
- **THEN** 后续 Space 或 Enter 继续到达当前 Compose 控件，操作对应筛选
- **AND** 浏览器焦点不得因临时输入框销毁落回 BODY，也不得抢回用户主动移到其他控件或窗口的焦点

## MODIFIED Requirements

### Requirement: Authenticated Compose destinations use one shared page-title hierarchy

所有已登录 Compose 路由 MUST 由同一应用外框组织一级导航、页面标题、账号操作和路由内容。收支账本、当前持仓、投资事件和管理 MUST 保持为四个同级导航目的地；分类管理 MUST 按 `workspace/workspace-management` 合并到管理页，不另设一级入口；账单导入 MUST 是从收支账本打开的二级页面，不得出现在全局侧栏。`REGULAR` 和 `WIDE` MUST 默认显示可展开的图标侧栏；支持鼠标悬停时，指针进入侧栏 MUST 自动展开，离开侧栏及账号面板后 MUST 自动收起。鼠标点击导航项造成的焦点 MUST NOT 阻止指针离开后收起。侧栏已展开时，激活顶部控制 MUST 立即收起侧栏，并在指针或键盘焦点仍处于侧栏/账号面板内时抑制自动展开；指针和焦点离开后 MUST 恢复悬停展开。无悬停能力的设备 MUST 保留通过控制点击展开或收起的能力；键盘焦点仍 MUST 展开侧栏以支持键盘导航。悬停头像 MUST 打开账号面板；鼠标进入面板后 MUST 保持打开，离开头像与面板后 MUST 关闭。`COMPACT` MUST 使用可从顶栏打开的模态抽屉。一级目的地 MUST 在顶栏显示唯一页面标题，二级页面 MUST 在自身容器标题栏显示唯一页面标题，正文 MUST 不重复当前页面标题。身份与工作区操作 MUST 从侧栏底部的头像入口访问，顶栏 MUST 不再放置工作区切换或退出登录入口。头像 MUST 使用会话邮箱首字母，不得伪装成可上传或编辑的个人头像。

#### Scenario: 打开一级目的地

- **WHEN** 使用者在任一逻辑窗口等级打开收支账本、收支分类、当前持仓、投资事件、工作区管理或已登录邀请页面
- **THEN** 页面 MUST 显示当前目的地标题，四个导航目的地 MUST 作为同级入口展示
- **AND** 页面 MUST 保留该目的地需要的导航与正文内容
- **AND** 标题 MUST 只显示一次

#### Scenario: 在 regular 和 wide 窗口导航

- **WHEN** 使用者在 `REGULAR` 或 `WIDE` 窗口首次进入已登录页面
- **THEN** 侧栏 MUST 默认收起并显示四个一级目的地的图标
- **AND** 展开操作 MUST 显示每个目的地的文字，收起操作 MUST 恢复图标侧栏
- **AND** 导航切换 MUST 更新选中项和顶栏页面标题
- **AND** 图标项 MUST 提供可感知的名称与焦点样式

#### Scenario: 悬停展开侧栏与账号面板

- **WHEN** 使用者在支持悬停的 `REGULAR` 或 `WIDE` 窗口将鼠标移入侧栏任意区域
- **THEN** 侧栏 MUST 自动展开并显示目的地名称
- **AND** 鼠标离开侧栏及其账号面板后，侧栏 MUST 自动收起
- **AND** 鼠标悬停底部头像 MUST 自动打开账号面板，鼠标从头像移入面板时 MUST 保持打开
- **AND** 触屏 MUST 可通过侧栏控制按钮展开或收起；键盘 MUST 可通过聚焦和激活相同操作

#### Scenario: 鼠标导航不会阻止侧栏收起

- **WHEN** 使用者用鼠标点击侧栏目的地后将指针移出侧栏和账号面板
- **THEN** 侧栏 MUST 自动收起，即使点击产生的焦点仍留在目的地上
- **AND** 使用键盘移动焦点时，侧栏 MUST 在焦点位于侧栏内时保持展开

#### Scenario: 收起悬停展开的侧栏

- **WHEN** 使用者在侧栏因悬停展开时激活顶部收起控制
- **THEN** 侧栏 MUST 立即收起，并在指针或键盘焦点仍处于侧栏或账号面板内时保持收起
- **AND** 指针与焦点离开后再次将鼠标移入侧栏 MUST 恢复自动展开

#### Scenario: 在 compact 窗口导航

- **WHEN** 使用者在 `COMPACT` 窗口打开导航抽屉
- **THEN** 抽屉 MUST 按同一级顺序列出四个目的地及其可见名称
- **AND** 抽屉 MUST 在底部提供头像入口，且不得遮挡页面标题或造成横向溢出

#### Scenario: 打开账号与工作区面板

- **WHEN** 使用者点击侧栏底部头像
- **THEN** 账号操作面板 MUST 显示当前认证邮箱、可访问工作区列表、活动工作区标记与每个工作区的角色
- **AND** 面板 MUST 提供工作区管理入口和退出登录操作
- **AND** 选择另一工作区时 MUST 沿用现有工作区访问、路由更新和错误处理语义
- **AND** 面板 MUST 在当前窗口内完整可见，并支持键盘聚焦、激活、Escape 关闭及焦点返回头像

#### Scenario: 返回、切换工作区或退出登录

- **WHEN** 使用者打开任一已登录页面或账号操作面板
- **THEN** 适用时的返回操作、工作区切换、工作区管理、退出登录和响应式导航 MUST 继续可用
- **AND** 退出登录 MUST 沿用现有会话清除与登录入口语义
- **AND** 导航、正文与账号操作面板 MUST 不发生遮挡、焦点丢失或横向溢出
