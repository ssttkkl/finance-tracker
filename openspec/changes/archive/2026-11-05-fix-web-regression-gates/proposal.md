## Why

完整 Web 回归的 183 个案例中有 26 个失败，既有断言与现行导航、筛选、布局合同的漂移，也有 Compose Web 没有正确导出控件角色和禁用状态的实际缺陷。Python 工具文件定义 11 项测试，但直接入口提前调用 unittest，只执行前 6 项。

## What Changes

- 按现行规格修复 26 个浏览器失败：更新过时导航、筛选草稿、日期和布局断言，修正分类模拟数据的路径与修订一致性，保留对应用户行为和安全断言。
- 为受影响按钮与备注单选项补齐 Web 平台的可访问角色、禁用和选中状态导出；状态来自同一 Compose 调用点，不从文案推测，不修改依赖产物。
- 修复 Web 搜索输入框销毁导致的浏览器焦点丢失，保留 Tab 后当前筛选控件的键盘激活能力。
- 修复快速提交后、UI 尚未重组时误弹放弃修改提示的问题，复用当前任务状态的既有关闭保护；完整回归同时校正导入关闭的旧镜像断言。
- 用真实点击与键盘验证登录忙碌锁定，避免测试直接改写透明语义镜像；保留邮箱/密码锁定、单次请求及错误后的输入保留。
- 修正共享展示规格里已过时的独立分类导航描述，引用管理页合同。
- 将 Python 测试入口放到所有测试定义之后，直接入口与 discovery 均收集并执行 11 项。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `shared/cross-platform-presentation`：明确控件角色和真实状态的跨端可访问语义，纠正与管理页冲突的旧一级导航描述。

## Impact

涉及 Compose 共享页面的 Web 语义适配、Web QA、Python 工具测试入口、功能地图和对应文档。无新依赖、后端接口、持久化或财务规则变化；不重做页面，不改变已批准的信息架构和视觉尺寸，不恢复旧导航。按 A 类处理未知根因和跨页面验证范围。验收为完整 183 项 E2E、两种入口的 11 项 Python 测试及受影响跨端编译/单测通过；执行独立工程、UI 复用和设计审查。发布动作另按具体授权执行，回滚使用本 change 前的 Git 提交，不涉及数据回滚。
