## ADDED Requirements

### Requirement: CLI 整批核对的计算与反馈

CLI MUST 使用同一份整批核对计算产物确认未改变的批次。复用受原工作区、账本事实版本、规则版本和核对修订约束。已有冻结尝试遵循原键恢复合同。

#### Scenario: 独立进程确认未变化的批次

- **WHEN** 同一批的核对、资料和事实版本均未变化，并从新的 CLI 进程确认
- **THEN** 使用已核对的完整请求、原选择和结果上下文，保留跨来源关系与一次原子提交

#### Scenario: 大批计算阶段反馈

- **WHEN** CLI 正在核对或确认多文件导入
- **THEN** 将实际阶段进展写至标准错误，`--json` 的标准输出保留单个机器可读结果
