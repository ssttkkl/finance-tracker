## MODIFIED Requirements

### Requirement: 收支账本表格列与交易信息层级

Compose 收支账本在 `REGULAR` 与 `WIDE` MUST 使用一致的桌面表格列顺序：选择框、发生时间、账户、交易信息、分类、流水类型、金额和行操作。上述列宽 MUST 依次为 5%、12%、15%、24%、12%、11%、13% 和 8%。交易信息列 MUST 先显示交易对方，再在其下显示备注；任一字段缺失时 MUST 保留其行位置并以短横线表示。`COMPACT` MUST 继续使用流水卡片，并让备注紧接交易对方显示。

#### Scenario: Regular 与 Wide 使用一致的表格列

- **GIVEN** 收支账本在 `REGULAR` 或 `WIDE` 窗口展示流水
- **WHEN** 列表含有可选择流水
- **THEN** 表格 MUST 依次呈现选择、发生时间、账户、交易信息、分类、流水类型、金额和行操作
- **AND** 交易信息列 MUST 在同一列内先显示交易对方，再显示备注
- **AND** 交易对方或备注缺失时 MUST 保留两行结构

#### Scenario: Compact 卡片显示交易对方和备注

- **GIVEN** 收支账本在 `COMPACT` 窗口展示流水卡片
- **WHEN** 流水包含交易对方和备注
- **THEN** 卡片 MUST 将交易对方和备注相邻展示，交易对方先于备注
- **AND** 缺失值 MUST 使用短横线占位

### Requirement: 新增、详情和编辑共用响应式模态信息面板

使用者从收支账本新建流水、打开收支详情或编辑现有流水时 MUST 使用同一响应式模态信息面板。`COMPACT` MUST 全屏呈现；`REGULAR` 和 `WIDE` MUST 从右侧呈现面板，账本保持可见但不可操作。面板 MUST 隔离背景交互并支持 Escape 或系统返回关闭。Compose 面板 MUST 沿用 Compose 与平台默认焦点行为，不得额外请求初始焦点或在关闭时显式恢复触发入口焦点；此规则只约束共享 Compose 面板，不移除其他功能（例如导入导航）已有的焦点逻辑。详情摘要 MUST 以金额和币种为视觉重心，交易对方 MUST 为次级识别信息；经济类型和发生时间 MUST 进入下方流水信息字段组，与账户、流水类型、适用的业务细分、分类、备注和来源一起在面板中平铺，默认以标签与值分列组织；受限宽度或字体放大导致分列不可读时 MUST 纵向排列，标签先于值。流水信息 MUST 不使用卡片外框、阴影或替代背景块；凭证成员、组成及退款时间线 MUST 归入相应的信息区域。存在关联事实时，详情 MUST 使用独立的 Material 3 ElevatedCard，以默认 `surfaceContainerLow` 前景角色呈现默认收起的「关联流水」区域；展开内容 MUST 留在该卡片内，并在同一详情面板中分组展示当前流水与关联流水，保留每笔流水的可核对信息和现有关联管理操作。关联卡片 MUST 与平铺信息组相互独立，不得嵌套；详情面板内不得再叠加 Dialog 或 Bottom Sheet。单源收支 MUST 不显示空的凭证或关联区域。编辑 MUST 在当前面板内切换，取消后回到原详情或收支账本，保存后展示更新结果。现有新增、编辑、删除、凭证、关联操作、权限、字段校验、错误、忙碌状态和危险确认语义 MUST 保持不变。

#### Scenario: 从列表打开详情或新增流水

- **WHEN** 使用者在 `COMPACT`、`REGULAR` 或 `WIDE` 窗口打开某条流水详情或选择「记一笔」
- **THEN** `COMPACT` MUST 显示全屏面板，`REGULAR` 和 `WIDE` MUST 显示右侧模态面板
- **AND** `REGULAR` 和 `WIDE` 中的账本 MUST 保持可见但不可操作
- **AND** 打开期间账本保持可见但不可操作

#### Scenario: 从收支详情编辑并返回

- **WHEN** 使用者在详情中选择编辑、修改字段后取消或保存
- **THEN** 编辑表单 MUST 在同一面板内呈现并保留已有字段、校验和权限限制
- **AND** 取消 MUST 返回原收支详情，保存 MUST 返回更新后的详情并刷新账本结果
- **AND** 需要确认关联影响或删除影响时 MUST 保留既有的明确确认流程

#### Scenario: 键盘关闭 Compose 流水面板

- **WHEN** 使用者通过浏览器键盘打开共享 Compose 流水面板并按 Escape
- **THEN** 面板 MUST 关闭，背景账本 MUST 恢复可交互
- **AND** 面板 MUST 不请求专属初始焦点或在关闭后显式恢复焦点到触发入口
- **AND** 其他功能已有的键盘与焦点行为 MUST 保持不变

#### Scenario: 查看单源或有关联流水的收支详情

- **WHEN** 使用者打开单源收支或包含凭证、关联流水的收支
- **THEN** 详情 MUST 首先展示完成核对所需的主要收支信息
- **AND** 摘要 MUST 只保留金额主导及次级交易对方，类型和时间 MUST 在下方流水信息中显示
- **AND** 流水信息 MUST 直接平铺于中性面板 Surface，关联流水 ElevatedCard MUST 继续使用 `surfaceContainerLow` 前景角色，且不得与其他卡片嵌套
- **AND** 主要属性 MUST 默认按标签与值分列展示，受限宽度或放大字体时 MUST 允许标签在上、值在下的纵向排列；来源、凭证成员、组成、退款时间线及关联流水 MUST 在次级区域分组展示，且不得暴露实现层术语
- **AND** 单源收支 MUST 不显示空的凭证或关联区域

#### Scenario: 在详情内展开已关联流水

- **WHEN** 使用者打开包含已接受关系或相关凭证流水的详情并展开「关联流水」区域
- **THEN** 区域 MUST 默认收起，并通过「查看关联流水」及关联数量让其可发现
- **AND** 折叠入口及展开内容 MUST 位于独立的 Material 3 ElevatedCard 内
- **AND** 展开后 MUST 在当前详情面板内分组显示当前流水与每条关联流水的交易对方、金额、发生时间、账户，以及适用的流水类型、分类和备注
- **AND** 展开区域 MUST 保留现有编辑关联流水、修改关系类型、取消关联及危险色解散关系操作
- **AND** 展开 MUST 不打开第二个 Dialog、Bottom Sheet 或路由
