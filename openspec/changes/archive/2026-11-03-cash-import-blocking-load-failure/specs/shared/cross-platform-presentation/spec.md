## ADDED Requirements

### Requirement: 现金导入页辅助数据失败阻塞流程并区分恢复入口

Compose Web、Android、iOS 现金导入页进入时读取账户、分类或账本选项失败，或导入账户列表在请求结束后仍未就绪且存在错误时，MUST 阻塞当前导入流程。明确网络或临时服务故障 MUST 显示具体原因及“重试”入口；内部程序错误 MUST 显示“系统错误”，且 MUST NOT 提供普通重试。加载中 MUST NOT 显示失败文案或重试。关闭 MUST 保留已有恢复指针并返回，不发送额外取消请求；重新进入 MUST 使用已有恢复信息读取任务。账户已就绪后的普通操作错误不适用本阻塞规则。

#### Scenario: 辅助数据读取失败

- **WHEN** 进入现金导入页后任一账户、分类或账本选项读取失败
- **THEN** 页面 MUST 显示对应原因的阻塞提示，且不显示文件步骤、账户映射步骤或“下一步”操作
- **AND** 明确网络或临时服务故障提供重试，程序错误只显示“系统错误”及安全退出

#### Scenario: 导入账户列表未就绪

- **WHEN** 导入账户恢复请求结束，账户列表仍未就绪且存在错误
- **THEN** 页面 MUST 进入与辅助数据失败相同的阻塞提示
- **AND** 页面 MUST NOT 把账户已就绪后的操作错误当作整页阻塞

#### Scenario: 加载中不显示失败

- **WHEN** 辅助数据或导入账户列表仍在加载
- **THEN** 页面 MUST NOT 显示错误文案或重试按钮

#### Scenario: 失败后关闭保留恢复

- **WHEN** 已恢复的导入会话因初始辅助数据失败而阻断，使用者点击关闭
- **THEN** 页面 MUST 返回且保留该会话的恢复指针，不发送额外取消请求
- **AND** 重新进入 MUST 重新读取该任务和辅助数据
