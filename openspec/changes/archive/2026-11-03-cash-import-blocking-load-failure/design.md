# 导入页初始加载失败

导入任务需要账户、分类和账本选项才能继续；辅助读取失败或导入账户恢复完成后未就绪时，按故障原因用错误文字及适用的重试动作替代步骤区域。标题与关闭按钮保留，重新进入使用既有加载和恢复流程。账户已就绪后的操作错误仍由原局部交互处理。

使用 Material 3 `Text` 的错误色角色，保留既有全屏模态任务、主题、排版和固定标题。加载中只禁用依赖尚未就绪的操作，不显示失败或裸重试；重试复用 Material 3 TextButton，不新增 token、依赖或恢复模型。HTML 原型不适用：本次局部失败呈现，不是重大 UI 重构。

Web、Android 和 iOS 共享同一判定；Web 以 390 px 代表视口验证失败和重新进入，原生仅相称编译与单测。关闭路径仍保护已有任务及提交未知状态。回滚恢复原裸重试和准备区错误显示，不涉及 schema 或账本事实。

初始加载失败时关闭直接返回并保留已有恢复指针，不发送额外取消请求；重新进入读取同一任务，未知提交仍沿用原保护边界。
