## ADDED Requirements

### Requirement: 导入文件名按上传原样展示

现金导入会话 MUST 在文件条目中展示用户上传的文件名原文。服务端 MUST NOT 因密码、账号、`尾号`、扩展名或括号内容改写文件名来脱敏或重命名。协议边界 MUST 只允许去除路径部分（取 basename）并将文件名截断到 255 字符；空文件名回退为“账单”。本要求只约束文件条目名称，不改变来源账户标签的脱敏规则。文件名文本中的密码字样属于用户自带的原始文本，不构成用户填写的解密密码字段值。

#### Scenario: 文件名含密码与完整账号

- **WHEN** 使用者上传名为 `银行_1234567890123456_密码=synthetic-secret.pdf` 的文件
- **THEN** 会话与页面返回的文件名 MUST 为 `银行_1234567890123456_密码=synthetic-secret.pdf`
- **AND** 系统 MUST NOT 删除密码片段，也 MUST NOT 把完整账号替换为尾号

#### Scenario: 文件名只按 basename 和长度边界处理

- **WHEN** 上传文件名包含路径分隔符或超过 255 字符
- **THEN** 系统 MUST 只保留最后一个路径段，并把结果截断到 255 字符
- **AND** 系统 MUST NOT 再做其他改写

#### Scenario: 来源账户标签仍按账户合同脱敏

- **WHEN** 文件名被用作微信缺少昵称时的来源账户会话标签，且文件名包含长数字账号
- **THEN** 该会话标签 MUST 仍按来源账户标签规则脱敏，不受文件条目原样展示规则影响

## MODIFIED Requirements

### Requirement: 导入失败不泄露敏感来源数据

解密、解析、映射、金额、币种、时间及持久化错误 MUST 返回可定位对象的安全业务原因；确认前可定位的文件／来源业务问题不使会话整体失败；内部程序错误拒绝预览，提交新增异常使整次业务写入回滚。全局临时存储或数据库不可用 MUST 失败关闭，不回退未受控目录。用户填写的解密密码字段值、完整账号证据、Token、路径和来源正文不得出现在日志、URL、错误或客户端长期存储；用户上传的文件名文本按「导入文件名按上传原样展示」处理，可包含密码字样或完整账号，但不得被当作密码字段值或账户身份证据使用。密码仅用于上传或重传当次解析请求。

#### Scenario: 密码错误

- **WHEN** 某文件密码无效
- **THEN** 标记该文件并保留重传入口，其他文件继续，响应日志无密码正文

#### Scenario: 持久化错误

- **WHEN** 任一执行项无法保存
- **THEN** 整次事务回滚并返回安全错误，不将异常转为行级跳过

#### Scenario: 全局存储不可用

- **WHEN** 无法安全保存或读取计划
- **THEN** 请求级失败，不写部分业务账本，不落不受控路径

#### Scenario: 加密 PDF 密码错误

- **WHEN** 使用者提供的 PDF 密码无法解密账单
- **THEN** 页面 MUST 返回明确失败且不创建账单账户映射或账本记录
- **AND** 日志、API 错误和页面文案不得包含用户填写的密码字段值或账单正文

#### Scenario: 临时存储不可用

- **WHEN** R2 读取、写入或删除失败
- **THEN** 系统 MUST 返回可识别的临时存储错误，不得写入部分账本记录或把敏感文件回退到未受控的本地路径

#### Scenario: 加密 PDF 尚未提供密码

- **WHEN** 使用者选择需要密码的 PDF 账单且尚未提供密码
- **THEN** API MUST 返回稳定的 `import_password_required` 错误码
- **AND** 页面 MUST 停留在选择文件步骤，显示密码输入和“下一步”入口，不得把该状态显示为渠道或来源账户无法识别

#### Scenario: 本地提前提示受保护账单

- **WHEN** 使用者选择的 PDF 文件在本地字节检查中包含标准加密标记
- **THEN** 页面 MUST 在开始服务端扫描前立即显示账单密码输入和“下一步”入口
- **AND** 页面 MUST NOT 因该本地检查把文件内容、密码或完整来源数据保存到浏览器持久化
- **AND** 服务端仍 MUST 在后续扫描、预览或确认阶段完成最终密码校验；本地未识别到标记时仍走服务端扫描兜底

#### Scenario: 页面通过下一步提交加密 PDF 密码
- **WHEN** 使用者在选择文件步骤输入 PDF 密码并点击“下一步”
- **THEN** 页面 MUST 通过受限请求头把密码传递给对应导入阶段
- **AND** 用户填写的密码字段值 MUST NOT 出现在 URL、日志、错误响应、预览数据或持久化账本数据中；文件名文本按「导入文件名按上传原样展示」处理
- **AND** 密码错误 MUST 返回 `import_password_invalid`，且不得创建账单账户映射或账本记录

#### Scenario: 无密码账单自动进入账户映射

- **WHEN** 使用者选择的账单不需要密码且扫描成功
- **THEN** 页面 MUST 在解析完成后直接进入账户映射步骤
- **AND** 选择文件步骤不得显示重复的“重新识别”或“选择账单文件”操作

#### Scenario: 返回后继续已识别账单

- **WHEN** 使用者从账户映射步骤返回选择文件步骤，且已选择的文件和扫描结果仍然有效
- **THEN** 页面 MUST 保留文件名称、扫描结果和后续可用的导入令牌
- **AND** 点击“下一步” MUST 直接回到账户映射步骤，不得重复上传或扫描文件

#### Scenario: 后续阶段再次需要密码

- **WHEN** 使用者在映射、预览或确认阶段提交加密 PDF，且当前密码已失效或未被接受
- **THEN** 页面 MUST 回到选择文件步骤并保留已选文件
- **AND** 页面 MUST 清空失效密码、清除后续映射、预览或配对结果并重新显示密码输入
- **AND** 页面 MUST 显示对应的密码错误，不得显示笼统的预览失败或确认失败
