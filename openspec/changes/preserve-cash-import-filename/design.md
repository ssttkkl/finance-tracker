# 文件名展示边界

## 实现选择

文件条目继续复用现有 `display_name`，由 `_display_filename` 仅取 basename 并截断到 255 字符，空值回退为“账单”。删除密码片段、括号和长数字改写，满足使用者核对实际文件名的要求；保留密码清理会与该要求冲突。

来源账户标签有独立含义，仍由 `_label` 脱敏；微信缺少昵称时也通过该函数生成标签。文件名不作为来源身份或跨导入账户映射依据。

## 风险与回滚

用户自带的文件名可能包含密码字样和完整账号，按已确认要求返回给上传者；解密密码字段仍只用于当次请求，日志、诊断和账本不保存该字段。原有暂存 TTL、归属和长度约束继续生效。

无数据库或协议结构迁移。恢复原文件名处理与对应测试即可回滚；既有临时会话的名称随 TTL 过期，不进行迁移。
