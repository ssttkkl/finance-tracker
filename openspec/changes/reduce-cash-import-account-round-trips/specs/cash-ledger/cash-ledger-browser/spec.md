## MODIFIED Requirements

### Requirement: 导入账户准备使用独立账户命令

账户准备 MUST 显示服务端来源分组、建议与本次选择，并允许暂不选择。自动建议仅依据来源身份及账户的有效类型／状态；币种不足 MUST NOT 隐藏唯一身份匹配的建议。不得显示分区级新建账户按钮或账户编辑按钮；每组目标账户下拉菜单 MUST 含“＋新建账户”选项。选择后立即打开独立新建账户表单，并预填来源账户名称、来源币种；账户类型按既有 Web 规则从名称推断，名称包含“花呗”或“信用卡”时为 `loan`，其余为 `cash`。创建成功后 MUST 返回原来源组并选中新账户；取消创建不得更改映射。保存成功的真实账户才可选择，创建立即生效且不随导入事务自动回滚。所选账户缺少来源币种时，界面不显示缺币种警示；点击“下一步”时，客户端 MUST 按目标账户汇总所有已选来源组所需币种，优先复用本次选择时读取的账户快照中的币种与修订；缺少快照的账户只补读一次，已有快照的账户不得重复读取。MUST 通过一次批量请求提交所有缺项，每项携带独立幂等键与自己的期望修订；不得逐条修改。批量结果 MUST 逐项采纳：成功项使用响应中的最新修订更新所有对应来源选择；失败项保留该项的安全原因；全部成功后生成导入计划。明确失败留在账户步骤显示安全原因并允许再次点击；未知结果须先核实。此修改进入既有账户退出补偿链。未完成且未有成功导入业务写入时退出，若存在账户改动 MUST 合并询问撤销并退出、保留并退出或继续导入；未知结果先核实。安全撤销仅使用普通账户命令及真实连续修订证据，不猜测刷新前旧值。

#### Scenario: 创建后选择

- **WHEN** 用户从某来源账户的目标账户下拉菜单选择“＋新建账户”并成功保存
- **THEN** 表单预填该来源的名称和币种，按名称推断账户类型；保存后回到同一来源组并选中新账户，取消后续导入不会自动删除它

#### Scenario: 币种不足仍自动建议并在下一步补齐

- **WHEN** 已选账本账户未支持来源组中的一个或多个币种
- **THEN** 该账户仍作为建议并自动选中；点击“下一步”时，按目标账户合并所有来源组所需币种，只提交一次批量补齐请求，保留原有币种并补入缺项
- **AND** 不对已有快照的账户重复读取，也不逐条修改；每项成功后所有对应映射使用该项最新修订再生成预览
- **AND** 存在失败项时留在当前步骤显示该项安全原因并允许重试；结果未知先核实

#### Scenario: 下一步前账户已被其他操作修改

- **WHEN** 选择的账户快照在点击“下一步”前已被其他操作修改，批量补齐中的该项修订不再匹配
- **THEN** 该项返回 `account_changed` 且不覆盖当前账户，界面留在账户步骤提示重新选择或重试
- **AND** 同批其他修订匹配的项仍可成功，其映射使用各自新修订；不得因一项冲突重放或覆盖全部账户

#### Scenario: 新账户已被其他记录使用

- **WHEN** 用户选择撤销并退出但账户已被其他记录引用
- **THEN** 保留不能安全撤销的改动，显示具体业务原因，不删除被引用账户

#### Scenario: 已持久化失败结果但没有成功业务写入

- **WHEN** 收据为 `committed=true/status=failed` 且不存在成功业务写入，用户退出时仍有独立账户改动
- **THEN** 仍提供安全撤销／保留／继续的退出选择，不仅凭结果阶段或 `committed` 跳过询问；成功、部分完成、仅草稿和正常无新增结果不触发撤销

#### Scenario: 刷新后无法恢复旧值

- **WHEN** 恢复任务时只有账户命令标识，没有完整旧值和连续修订证据
- **THEN** 可核实命令结果，但不提供虚假的自动还原；退出可保留实际账户状态
