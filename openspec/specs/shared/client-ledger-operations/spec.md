# shared/client-ledger-operations Specification

## Purpose

提供可由不同客户端入口直接调用的账本操作。用户经终端或客户端宿主执行同一任务时，使用相同的账户与工作区范围、账本查询、现金导入核对和提交恢复规则，得到一致的业务结果。

## Requirements

### Requirement: 一期账本操作可通过有类型的 Kotlin 接口调用

系统 MUST 为一期范围内的会话与工作区、财务账户、收支与分类、现金导入提供宿主可直接调用的 Kotlin 操作。操作 MUST 接受业务参数并返回有类型的结果或可识别错误；调用方无需构造命令行、启动 Node 进程或解析终端文本。CLI MUST 在生产路径上调用这些操作。

#### Scenario: 同一工作区查看月度支出

- **WHEN** Kotlin 调用方和 CLI 使用相同的工作区、时区、筛选条件与快照版本查询月度汇总
- **THEN** 两者 MUST 得到相同的精确分币种金额与数据版本；终端格式仅在 CLI 输出时生成

#### Scenario: 同一批次核对与接续提交

- **WHEN** 调用方提供相同的文件、账户选择与核对版本，并在网络中断后恢复原操作
- **THEN** 操作 MUST 保留同样的来源、待处理原因、核对结果及原提交身份；相同的服务端结果在两种调用方式下表达为相同的成功、冲突或待核实状态

### Requirement: 宿主提供平台能力并约束访问范围

共享操作 MUST 使用宿主提供的会话范围、文件访问和存储能力。已绑定的工作区、核对版本、权限检查和写入恢复规则 MUST 适用于所有调用入口，后端保有最终鉴权与落账责任。

#### Scenario: 调用参数与绑定范围发生冲突

- **WHEN** 其他进程切换了活动工作区，调用方携带旧范围的批次或收支标识提交操作
- **THEN** 操作 MUST 按原范围安全完成或报告冲突，不能将写入转移到新工作区
