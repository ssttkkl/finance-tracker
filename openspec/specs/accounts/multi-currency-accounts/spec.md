# 多币种账户

## Purpose

定义一个账户持有多项分币种余额时的账户生命周期、写入消歧、账单路由和跨币种资金移动行为，确保币种始终显式、账户身份稳定且两端原始金额不被隐式换算。

## Requirements

### Requirement: 一个账户持有多项分币种余额
系统 MUST 允许同一工作区内的一个账户同时持有多个币种的独立余额，并按账户与币种共同确定余额。系统 MUST NOT 为账户设置隐式主币种或把某一币种当作未指定操作的默认值。

#### Scenario: 展示多币种账户
- **WHEN** 一个账户同时持有 CNY 和 USD 余额
- **THEN** 账户查询 MUST 返回同一账户下两项分币种余额，不得要求建立两个同名或带币种后缀的账户

### Requirement: 手工写入必须明确操作币种
会因同名多币种余额产生歧义的新增现金流水、余额校准和转账操作 MUST 显式指定币种。金额与币种 MUST 在提交前验证，且系统不得从账户名称或既有余额猜测币种。

#### Scenario: 缺少操作币种
- **WHEN** 使用者向多币种账户新增现金流水但未指定币种
- **THEN** 系统 MUST 拒绝写入并提示指定币种

#### Scenario: 校准指定币种余额
- **WHEN** 使用者以精确十进制金额校准账户的 HKD 余额
- **THEN** 系统 MUST 只更新该账户的 HKD 分币种余额，其他币种余额保持不变

### Requirement: 账单按账户身份和行币种路由
账单导入 MUST 先根据来源行中的支付方式、卡号或映射规则解析工作区账户，再按业务行币种写入该账户的对应分币种余额。账户名称相同但币种不同不得产生新的物理账户。

#### Scenario: 一份账单包含多个币种
- **WHEN** 同一账单中的业务行被映射到同一账户且分别使用 CNY 与 JPY
- **THEN** 系统 MUST 把两行写入该账户的对应分币种余额，并保留各自币种

### Requirement: 跨币种转账保留两端原始金额
系统 MUST 支持账户之间或同一账户内部的跨币种资金移动，并分别保存转出端和转入端的精确金额与币种。跨币种操作不得要求两端金额相等，也不得隐式换算或发明汇率。

#### Scenario: 跨币种资金移动
- **WHEN** 使用者记录从 CNY 余额转出 `700.00` 并向 USD 余额转入 `100.00`
- **THEN** 系统 MUST 原样保存两端金额和币种，且不得把其中一端改写为另一币种

### Requirement: 账户身份在重命名和停用后保持稳定
账户重命名 MUST NOT 改变既有账本记录、来源追踪、交易关系和投影的归属。已被账本记录引用的账户 MUST NOT 被硬删除；系统必须先允许停用，并在仍有引用时拒绝删除。

#### Scenario: 重命名有历史记录的账户
- **WHEN** 使用者重命名一个已有现金流水和投资事件的账户
- **THEN** 全部既有记录和派生结果 MUST 继续归属于同一账户身份

#### Scenario: 删除被引用的账户
- **WHEN** 使用者尝试删除仍被账本记录引用的账户
- **THEN** 系统 MUST 拒绝删除，且不得级联删除账本记录
