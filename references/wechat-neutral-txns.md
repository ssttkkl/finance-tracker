# 微信中性交易

微信账单中的部分交易在“收/支”列标记为 `/`。当前转换器按交易类型和说明解释这些记录；不能只依金额正负或描述关键词推断方向。

## 当前识别类型

| 交易类型 | 现金流语义 |
|---|---|
| `零钱提现` | 微信零钱出账；支付方式中出现的银行卡是到账证据 |
| `充值`、`零钱充值` | 资金转入微信零钱，来源账户流出 |
| `购买理财通` | 购买操作的付款账户流出 |
| `信用卡还款` | 付款账户流出，分类为还款 |
| `零钱通存取`、`理财通` | 结合对方、商品和状态文本中的转出、取出、赎回、到账等信息判断流入；否则按流出处理 |

记录中的平台账户和对手账户由现金账单适配层归一；银行卡到账记录来自银行账单，再由关系流程判断是否与提现配对。

## 错误与跳过边界

金额无法解析或中性类型无法确定方向时，Kotlin 行归一保留 `amount_unreadable` 或 `direction_unrecognized`；不能将这些情况概括为静默跳过。无法读取的行结构另有明确未导入原因，后续按完整性规则生成草稿或未导入结果。新增交易类型前，应更新明确的方向规则和去标识化回归，避免把未知类型猜成收入或支出。
