# Alipay Mapping Patterns

支付宝账单 `收/付款方式` 列的可能取值及 `~/.ft/mapping.yaml` 对应规则。

## 基础支付方式

| 支付方式 | 规则 | 账户 | 说明 |
|----------|------|------|------|
| `账户余额` | `match: "余额"` | 支付宝余额 | 精确匹配 |
| `余额宝` | `match: "余额宝*"` | 支付宝余额 | 余额宝支付本质还是支付宝体系 |
| `花呗` / `花呗分期(N期)` | `match: "花呗*"` | 花呗 | 花呗及分期统一走花呗账户 |
| `工商银行储蓄卡(3697)*` | `match: "工商银行储蓄卡(3697)*"` | 工行借记卡 | 工行借记卡 |
| `工商银行信用卡(1200)*` | `match: "工商银行信用卡(1200)*"` | 工行信用卡(1200) | 主卡 |
| `工商银行信用卡(9166)*` | `match: "工商银行信用卡(9166)*"` | 工行信用卡(1200) | 附属卡，合并到主卡 |
| `建设银行储蓄卡(2820)*` | `match: "建设银行储蓄卡(2820)*"` | 建行储蓄卡(2820) | |
| `网商银行储蓄卡(4164)*` | `match: "网商银行储蓄卡(4164)*"` | 网商储蓄卡(4164) | |
| `哈啰骑行卡` / `单车骑行卡抵扣` | `match: "哈啰骑行卡*"` / `match: "单车骑行卡抵扣"` | 支付宝余额 | 0 元会员卡抵扣，保留记录 |
| `工商银行信用卡分期(1200)*` | `match: "工商银行信用卡分期(1200)*"` | 工行信用卡(1200) | 信用卡分期支付 |
| `(空字符串)` | `match: ""` | 支付宝余额 | 兜底 |

|--------------|------|------|

| `云闪付-中国工商银行(9166)*` | `match: "云闪付-中国工商银行(9166)*"` | 工行信用卡(1200) |

|--------------|------|------|

## 组合支付

支付宝支持多种支付方式组合，`收/付款方式` 以 `&` 连接。

### 组合支付 + 优惠/立减

优惠活动（随机立减、红包等）是折扣，实际资金走主支付方式。

| 原始支付方式 | 规则 | 账户 | 逻辑 |
|--------------|------|------|------|
| `账户余额&支付宝随机立减*` | `match: "账户余额&支付宝随机立减*"` | 支付宝余额 | 立减是折扣，钱从余额扣 |
| `账户余额&红包` | `match: "账户余额&*"` (兜底) | 支付宝余额 | 红包是折扣 |
| `工商银行信用卡(9166)&美国运通卡立减` | 走 `工商银行信用卡(9166)*` 规则 | 工行信用卡(1200) | 运通立减是折扣，钱走信用卡 |

### 组合支付 + 分期

| 原始支付方式 | 规则 | 账户 | 逻辑 |
|--------------|------|------|------|
| `账户余额&花呗分期(3期)` | `match: "账户余额&花呗分期*"` | 花呗 | 必须放在 `账户余额&*` 兜底规则之前 |
| `余额&花呗分期*` | `match: "余额&花呗分期*"` | 花呗 | 同上 |

## 规则排序要求

在 `mapping.yaml` 中，规则的先后顺序很重要：

1. **精确变体规则放前面** — `云闪付-中国工商银行(9166)*`, `中国建设银行储蓄卡(2820)*` 等
2. **花呗及分期变体放中间** — `花呗*`, `账户余额&花呗分期*`（必须在 `账户余额&*` 之前）
3. **支付方式基础规则** — `工商银行储蓄卡(3697)*`, `建设银行储蓄卡(2820)*`
4. **组合支付兜底** — `账户余额&*`（捕获所有其他组合）
5. **空字符串兜底** — `match: ""`

## 常见操作模式

批量导入时 mapping 缺失会导致 `ValueError`，修复方式：

```bash
# 1. 试转一个文件，看缺什么
ft convert 支付宝交易明细.csv -s alipay -o test.csv

# 2. 添加缺失规则到 ~/.ft/mapping.yaml

# 3. 重试该文件，直到成功
ft convert 支付宝交易明细.csv -s alipay -o alipay_ok.csv

# 4. 再处理下一个文件
```
