# 工行信用卡 PDF 格式

工行信用卡 PDF 由 `_read_icbc_raw` 通过 `extract_pdf_text` 读取，选择 `pdfplumber` 的 word-stream 布局，再由文本解析器识别交易。解析器根据账单文本中的“信用卡”标记区分信用卡和借记卡类型。

## 交易上下文

信用卡交易信息在提取文本中按日期、时间、卡号、借贷方向、币种、金额、入账信息、余额和交易说明等字段展开。字段可能跨行；解析器围绕金额行读取有限的前后文，识别交易方向、币种、商户和支付来源。

- “借”按消费/出账方向生成负金额；“贷”按入账方向保留正金额。
- 交易金额与入账金额可能同时出现，解析器需按交易上下文选择金额并处理重复字段。
- 商户名或支付来源可能出现在金额行之后，需检查当前上下文窗口，不应只向前搜索。
- 商户文本可能带有支付来源前缀；来源信息用于生成记录描述和关系证据。

真实账单的卡号、文件名、密码和交易记录不属于格式文档，不要复制进仓库。

## 当前解析实现

信用卡文本流与借记卡表格走不同的解析路径：信用卡由 `pdfplumber` word-stream 文本解析；借记卡用 `pdfplumber` 表格解析并过滤较大的水印字符。具体字段位置、错误行为和来源账户提取以 [工行银行卡 PDF 解析](icbc-statement-format.md) 和实现为准。

解析器及当前回归用例见 [`convert.py`](../src/ft/convert.py)、[`test_convert.py`](../tests/test_convert.py) 与 [`test_icbc_refund_pairing.py`](../tests/test_icbc_refund_pairing.py)。
