# 各来源数据格式

## 支付宝 CSV

**列（从导出文件第23行表头开始）：**

| 索引 | 列名 | 说明 | 示例 |
|------|------|------|------|
| 0 | 交易时间 | `YYYY-MM-DD HH:MM:SS` | 2026-06-06 23:46:23 |
| 1 | 交易分类 | 日用百货/商户消费/群收款/退款 | 商户消费 |
| 2 | 交易对方 | 商家或个人名称 | t***4 |
| 3 | 对方账号 | 脱敏账号 | 153******64 |
| 4 | 商品说明 | 商品描述（往往很长） | 镭风HD6450显卡... |
| 5 | 收/支 | 支出/收入/不计收支 | 支出 |
| 6 | 金额 | 数值 | 31.00 |
| 7 | **收/付款方式** | **去重关键字段** | 见下方 |
| 8 | 交易状态 | 等待确认收货/支付成功/已退款 | 支付成功 |
| 9 | 交易订单号 | 支付宝内部单号 | 2026060623001112651401489534 |
| 10 | 商家订单号 | 对面系统的单号 | T200P3306373178115004871 |
| 11 | 备注 | 通常为空 | |

**收/付款方式 取值分类：**

- `工商银行信用卡(1200)` — 工行信用卡(1200)支付
- `工商银行信用卡(1200)&千问每日必减` — 同卡+优惠券
- `工商银行信用卡(1200)&红包` — 同卡+红包
- `工商银行信用卡(1200)&食神卡点餐优惠` — 同卡+场景优惠
- `工商银行信用卡分期(1200) 6期` — 同卡分期（含"信用卡"关键词）
- `工商银行信用卡(9166)` — 另一张工行信用卡
- **其他**：`网商银行储蓄卡(4164)`, `建设银行储蓄卡(2820)`, `账户余额`
- 空字符串 — 转账/退款类不计收支的交易

**去重规则：含 "信用卡" 或 "花呗" → transfer；否则 → expense**

## 微信 Excel (xlsx)

**列（在表格内第18行左右）：**

| 索引 | 列名 | 说明 | 示例 |
|------|------|------|------|
| 0 | 交易时间 | `YYYY-MM-DD HH:MM:SS` | 2026-06-09 12:24:54 |
| 1 | 交易类型 | 商户消费/群收款/退款 | 商户消费 |
| 2 | 交易对方 | 商家或个人名称 | 便利蜂 |
| 3 | 商品 | 商品描述 | 便利蜂购物 |
| 4 | 收/支 | 支出/收入 | 支出 |
| 5 | 金额(元) | 数值 | 4.50 |
| 6 | **支付方式** | **去重关键字段** | 见下方 |
| 7 | 当前状态 | 支付成功/已退款 | 支付成功 |
| 8 | 交易单号 | 微信内部单号 | 4200003153202606099693705821 |
| 9 | 商户单号 | 对面系统的单号 | 21349326685783 |
| 10 | 备注 | 通常为 `/` | / |

**支付方式 取值分类：**

- `工商银行信用卡(1200)` — 信用卡支付
- `工商银行信用卡(9166)` — 另一张信用卡
- `零钱` — 微信零钱（现金）
- `建设银行储蓄卡(2820)` — 储蓄卡（现金）
- `/` — 收入类交易（红包/退款入账等）

**去重规则：含 "信用卡" 或 "花呗" → transfer；否则 → expense**

## 工行ICBC PDF (文本提取后)

### 借记卡(储蓄卡)

- 金额行特征：`^[+-][\d,]+\.\d{2}$`（带正负号，排除无符号的余额行）
- 日期行格式：`YYYY-MM-DD`
- 日期在金额行前最多11行内（摘要换行导致间隔大）
- 交易结构：日期→摘要→金额→余额→对方户名→对方账号→渠道
- 借记卡分类依赖上下文关键词匹配（工资/房租/购汇/基金等）
- 金额为正=流入，金额为负=流出

### 信用卡

- 金额全为正数
- `借`=消费 → 取负 → expense
- `贷`=还款/退款 → 留正 → transfer
- 同一交易可能有两重金额（交易金额+入账金额），靠(date, amount)去重
- 商户名提取优先级：美团支付->财付通->支付宝->京东支付->网银在线-
