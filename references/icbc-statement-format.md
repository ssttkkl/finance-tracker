# ICBC (工行) 银行卡 PDF 明细格式

## 解析工具链

```bash
brew install qpdf mupdf-tools
uv run ft import statement.pdf --source icbc --account Card --currency CNY \
  --password-file /path/to/mode-0600-password-file
```

Finance Tracker 在 mode-0700 临时目录中调用 qpdf/mutool，完成后自动删除解密产物；不要在账单
目录手工生成明文 PDF 或文本 sidecar。

**避免使用 pdftotext / pdfminer** — 工行 PDF 含中文水印，这两种工具会混入水印文字。

## 1. 信用卡明细

**文件特征**：1MB+，10~34 页，卡号 6225/5276 开头。

**mutool 行模式**：
```
2026-01-01         ← 日期行（YYYY-MM-DD）
13:00:40           ← 时间
622599******1200   ← 交易卡号
借                 ← 收/支（借=消费，贷=还款）
人民币
16.30              ← 交易金额（正数，无+/-号）
人民币
16.30              ← 入账金额（重复，需去重）
-3,765.87          ← 账户余额
消费
美团支付-美团App霸王茶姬  ← 交易场所（可能换行）
```

**解析要点**：
- 金额为**正数**，「借」=消费(取负)，「贷」=还款(保持正)
- 双金额行（交易金额+入账金额）→ 靠 (date, amount, account, category) 四元组去重
- 商户名前缀优先级：美团支付-> 财付通-> 支付宝-> 京东支付-> 网银在线-

## 2. 借记账户明细

**文件特征**：~185KB，3 页，卡号 6212 开头。

**mutool 行模式**：
```
2026-01-12         ← 日期行
14:31:25           ← 时间
161402******4636
活期
00000
人民币
钞
工资               ← 摘要
1614
+[金额]         ← **金额行**（带 +/- 符号）
|[余额]          ← **余额行**（无符号！）
|[公司名]  ← 对方户名
1219****0038       ← 对方账号
其他               ← 渠道
```

**解析关键**：
- 金额行有 **+/- 前缀**，余额行无符号 → 用 `^([+-][\\d,]+\\.[\\d]{2})$` 过滤
- 日期在金额行前 **11 行**内（不是 10 行！受摘要换行影响，10 行会漏掉工资等长上文记录）
- 对方户名在金额行之后（金额→余额→对方户名→对方账号→渠道）
- `is_family` 判断先于 `is_transfer_to_self`（因家人卡号也含 `****`）

**分类规则表**：

| 特征 | 分类 | 说明 |
|------|------|------|
| 工资/年终 | income | 入账 |
| 摘要=利息 | income | 活期利息 |
| 银联入账/他行汇入 | income | 跨行转入 |
|| [姓名] | income | 还款 |
| 网转 | income | 其他转入 |
| 含`****`且不是家人 | transfer | 转自己 |
| 购汇/跨境/美元 | transfer | 证券入金 |
| 基金购买 | transfer | 基金买入 |
| 基金赎回 | transfer | 基金赎回 |
|| [姓名] | expense | 给家人 |
| 北京信富/住房租赁 | expense | 房租 |
| 撤销 | 跳过 | 撤销交易 |

## 跨来源去重 (0误差: 支付方式分类法)

**不再需要跨表日期+金额匹配。** 支付宝和微信的导出文件自带了支付方式字段，直接告诉了你钱走的渠道。

| 来源 | 关键列 | 规则 |
|------|--------|------|
| 支付宝 CSV | `收/付款方式` (第8列) | 含"信用卡"或"花呗" → transfer；否则 → expense |
| 微信 Excel | `支付方式` (第7列) | 同上 |

**导入时直接分类，不需要 reconcile 阶段的跨表匹配。** 旧版 `dedup.py` 已删除。

为什么是 0 误差：同一天买 10 笔 ¥1.99，只要支付方式不同（3 笔信用卡、7 笔零钱），各自正确分类，互不干扰。
