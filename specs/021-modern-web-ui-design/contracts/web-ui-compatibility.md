# Web 界面兼容性合同

## 目的

Feature 021 只改变既有收支账本 Web 的展示层。本合同定义哪些用户可见与传输边界必须保持不变，并作为组件、浏览器和视觉快照回归的共同基线。

## 不变的读取接口

以下既有只读调用是唯一允许使用的前端读取接口：

| 读取目的 | 既有调用 | 不变要求 |
|---|---|---|
| 账户目录 | `fetchCashAccounts` | 请求时机、账户选项和失败重试不变 |
| 投影列表 | `fetchCashPage` | 筛选参数、游标、版本更新、加载/空/错误状态不变 |
| 证据详情 | `fetchEvidence` | 证据标识、字段、脱敏、失败重试和焦点恢复不变 |

不得新增、替换或修改 `web/src/api/` 调用，且不得新增后端 route、DTO、查询、持久化或外部请求。

## 不变的筛选合同

- 字段：开始日期、结束日期、账户、交易对方、分类、币种、最低金额、最高金额、经济类型、组成方式。
- 枚举：经济类型与组成方式的选项和传输值保持不变。
- 任一筛选变化后：游标栈重置到首页；其余筛选条件保持；请求取消和迟到响应保护继续生效。
- 列表不得展示“组成方式”列或关系摘要；组成方式仅存在于筛选与证据详情的既有关系信息中。

## 不变的列表与证据合同

### 投影列表

- 列顺序固定为：发生时间、账户、交易对方、备注、分类、金额、来源、证据入口。
- 金额继续显示 API 提供的精确十进制字符串和币种；不得使用浏览器浮点运算重新计算。
- `<caption>`、`<thead>`、`<th scope="col">` 保持存在；窄屏不得以 `display: none` 隐藏表头。
- “查看”入口的可访问名称必须含对应交易对方或“该记录”。

### 证据详情

- 展示投影结果、主记录、来源行快照、成员流水、已采用关系、未生效关系提示和退款时间线。
- 不删除字段，不改变字段含义、脱敏范围、错误合同或顺序语义。
- 打开后关闭按钮自动获焦；`Escape` 关闭；Tab 与 Shift+Tab 不离开详情；背景不可交互；关闭后焦点回到原触发入口。

## 版本更新与失败合同

| 情形 | 既有结果 |
|---|---|
| `projection.updated` | 关闭旧详情、回到第一页、保留筛选、显示更新提示并将焦点交给确认按钮 |
| `projection.unavailable` | 明确提示收支投影不可用，不回退显示原始现金流水 |
| `invalid_filter` / `invalid_cursor` | 使用既有可修正的中文错误说明 |
| `storage.*` / 请求失败 | 使用脱敏的可操作错误说明和重试入口 |
| 证据不完整 | 显示明确的详情不完整状态和重试入口 |

## 视觉快照合同

使用现有去标识化 Playwright fixture，分别捕获以下固定视口的快照：

- 1440 × 900：列表主流程、筛选、并列证据详情。
- 1024 × 768：并列详情临界布局。
- 768 × 1024：顶部导航、筛选重排和列表。
- 390 × 844：卡片列表、展开筛选和全屏证据详情。
- 同一 fixture 的加载、空、错误和证据详情状态。

快照更新必须人工检查，确认差异只来自批准的展示层改造。任何 API 请求、文本含义、字段、焦点或布局合同变化都不是允许的“视觉更新”。
