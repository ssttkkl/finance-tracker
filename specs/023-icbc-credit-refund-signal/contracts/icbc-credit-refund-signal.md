# 合同：工行卡退货退款信号

## 解析至来源行快照

| 输入 | 正式导入行 | `source_payload` | 不变量 |
|------|------------|------------------|--------|
| 工行信用卡、原生摘要 `退货`、正数 | `summary="退货"`，`refund_signal="icbc_credit_return"` | 保留同名键 | 对手方、备注、金额、类别、业务行标识不变。 |
| 工行借记卡、原生摘要 `退货`、正数 | `summary="退货"`，`refund_signal="icbc_debit_return"` | 保留同名键 | 对手方、备注、金额、类别、业务行标识不变。 |
| 工行信用卡或借记卡、非“退货”正数 | 无 `refund_signal` | 不误写退款信号 | 不因正数金额成为退款。 |
| 其他来源 | 无此来源专用信号 | 原样 | 不改变现有渠道语义。 |

## 关系检查

| 事实来源行快照 | 方向 | 退款种子资格 | 结果 |
|----------------|------|--------------|------|
| `bill_source=icbc_credit`，`refund_signal=icbc_credit_return` | 正数 | 是 | 进入既有第 D 阶段匹配。 |
| `bill_source=icbc_debit`，`refund_signal=icbc_debit_return` | 正数 | 是 | 进入既有第 D 阶段匹配。 |
| 仅有 `summary=退货`、没有正式 `refund_signal` | 正数 | 否 | 不作为历史兼容输入。 |
| 任何其他来源、同名字段 | 正数 | 否 | 不能因该字段成为退款。 |
| 以上任一来源，负数或非现金事实 | 非正数 / 非现金 | 否 | 不改变既有支出和投资处理。 |

具备种子资格只允许进入候选匹配，绝不保证自动接受；后续仍由既有时间、币种、商户、订单、金额、P2P 与幂等规则决定。
