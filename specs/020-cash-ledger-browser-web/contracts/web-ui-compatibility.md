# Web 界面兼容性合同

## 目的

本合同整合原 Feature 021 的展示层约束。收支账本 Web 只消费既有投影、账户和证据读取接口；不得新增或修改 `web/src/api/` 调用、后端 route、DTO、查询、持久化或外部请求。

## 筛选与连续加载

- 字段为开始日期、结束日期、账户、交易对方、分类、币种、最低金额、最高金额、经济类型和组成方式；筛选默认折叠并显示当前范围摘要。
- 筛选变化或 `projection.updated` 时，取消当前请求、递增请求代次、清空累计记录和 cursor，从 `null` cursor 重读；迟到响应不得污染当前列表。
- 使用 `next_cursor` 自动连续加载，并始终提供“加载更多”按钮作为键盘、辅助技术、observer 不可用和自动加载失败时的回退；不显示上一页或下一页。
- 同一 cursor 最多一个请求；成功追加按服务端排序并以 `projection_id` 去重；失败保留记录，仅允许人工重试；末批显示“已显示全部记录”。

## 列表、证据与无障碍

- 桌面 DOM 列顺序固定为发生时间、账户、交易对方、备注、分类、金额、来源、证据入口；组成方式只用于筛选和证据详情。
- 主列表、caption、加载和空状态使用“收支记录”“分类”“导入渠道”等业务表达，不显示 `projection`、`source_type`、cursor 或主记录发生时间。
- 窄屏卡片以真实文本显示分类和导入渠道；保留 `<caption>`、`<thead>`、`<th scope="col">` 和字段关联，表头不得以 `display: none` 隐藏。
- 金额保持 API 的精确十进制字符串；不使用浏览器浮点运算。
- 详情展示投影结果、主记录、来源行快照、成员流水、已采用关系、未生效关系提示和退款时间线；关闭按钮自动获焦，`Escape` 关闭，Tab 焦点圈定，背景不可交互，关闭后焦点回到触发入口。

## 失败、响应式与视觉快照

- `projection.updated` 取消追加、关闭旧详情、保留筛选并刷新首批；`projection.unavailable`、`invalid_filter`、`invalid_cursor`、`storage.*`、追加失败和证据不完整均使用既有脱敏文字与重试合同。
- 使用命名视觉令牌、现有 `Noto Sans SC` 和 `IBM Plex Mono`；1440 × 900、1024 × 768 支持并列详情，390 × 844 使用卡片与全屏详情；检查 320、375、414、768 px 的无横向溢出、焦点、触控目标和表头语义。
- 去标识化 Playwright 快照覆盖默认/展开筛选、追加加载/失败、末批、空、错误、移动字段和详情。只有确认差异属于批准的展示层变更时才更新基线。
