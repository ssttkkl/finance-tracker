# iOS + Computer Use 适配

本文件是 `alipay-bill` 的 iOS 执行后端。使用 Computer Use 技能操作用户的 iPhone 镜像；这里的设备和工具是实现手段，不是 `alipay-bill` 的业务定义。

## 能力与前置检查

选择本后端前确认：

- iPhone 镜像可见且可交互；
- Computer Use 能点击、返回、输入非敏感参数并读取页面状态；
- 支付宝已安装并能打开；
- 需要转交时，目标 Mac 已由用户明确指定且可在分享页面核对。

如果任一项不满足，回到主流程重新选择后端，不要把本后端当作可用。

## 参数映射

- `时间范围`：使用支付宝页面提供的 `最近一个月`、`最近三个月`、`最近一年` 或用户确认的 `自定义` 范围。
- `保存位置`：默认选择 iOS 文件保存页中的 `我的 iPhone`；用户明确指定其他位置时才改变。
- `转交=是`：必须同时存在用户明确指定的目标设备，例如 `huangwenlong的 Mac mini`。
- `接收方式`：固定选择 `支付宝`，不得改选邮箱或其他渠道。

## 操作步骤

1. 在 iPhone 镜像中打开支付宝。
2. 点击 `我的` → `账单` → 右上角 `…` → `开具交易流水证明`。
3. 选择 `用于个人对账`，点击 `申请`。
4. 到达面容 ID、支付密码或设备认证页面后，暂停操作，请用户在 iPhone 上完成认证。用户确认后再继续。
5. 在 `选择交易流水范围` 页面设置：
   - `交易类型`：`全部交易`；
   - `时间范围`：使用主流程传入的 `时间范围`；
   - `接收方式`：`支付宝`。
6. 点击 `下一步`，确认出现 `提交成功`，再点击 `完成`。这一步对应主流程的“申请已提交”。
7. 返回支付宝首页，在 `最近消息` 中等待「我的账单」出现 `您的交易流水证明已生成`。这一步对应“等待生成”。
8. 打开该消息，点击 `查看详情`；在 `申请记录` 中选择与本次时间范围匹配的最新记录，点击 `下载文件`。只有看到文件已生成的明确证据时才下载。
9. 在 iOS 保存页面选择 `我的 iPhone`，使用默认文件名保存，除非用户指定其他文件名。确认保存成功后报告文件位置。
10. `转交=否` 时结束。
11. `转交=是` 时，在文件分享页面选择用户明确授权的目标设备，等待状态变为 `已发送`；只有看到已发送才报告转交完成。

## 状态检查与恢复

- 误选 `邮箱`：返回 `接收方式`，改选 `支付宝`，再点击 `下一步`。
- `提交成功` 页面没有关闭：点击底部 `完成` 或使用可见返回按钮；不要再次点击 `申请`。
- 最近消息尚未出现：保留已提交申请，告知支付宝可能需要最多 24 小时；不要创建重复申请。
- 申请记录中存在相同时间范围：选择最新且与本次申请匹配的记录，不重新提交。
- 下载后未出现 iOS 保存页：先确认下载动作是否成功，再重试下载；不要重新申请。
- AirDrop 显示 `等待中`：不要反复重试；检查目标 Mac 是否在附近且允许被发现，并报告接收方可能需要接受传输。
- 目标设备与用户指定不一致：停止转交并请求用户确认，不要凭设备名称相似度猜测。

## 认证与隐私

- 不读取、输入、复述、保存或推测支付宝支付密码、面容 ID 或设备密码。
- 认证必须由用户在 iPhone 上完成；Computer Use 只等待用户确认，不代替认证。
- 不截取、复制或外传交易流水文件中的敏感内容；仅报告业务状态和保存结果。
