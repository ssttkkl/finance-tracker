# 支付宝账单导出

将支付宝「交易流水证明」作为 `alipay-bill` 处理。核心流程不绑定手机系统、镜像方式或自动化工具；当前可用后端见 [references/ios-computer-use.md](references/ios-computer-use.md)。未来新增 Android、ADB 或其他后端时，只新增适配文件并遵守下方契约，不改写本流程。

## 入参

- `时间范围`：申请交易流水证明的范围，默认 `最近三个月`。平台支持的选项以当前后端实际页面为准；用户指定 `自定义` 时，先确认起止日期。
- `保存位置`：默认保存到当前后端可直接控制的设备本地文件空间。除非用户明确指定，不改变文件名或保存位置。
- `转交`：默认 `否`。只有用户明确授权并指定目标设备或渠道时，才在本地保存成功后执行转交。

示例：

```text
$alipay-bill 时间范围=最近三个月 转交=否
$alipay-bill 时间范围=最近一个月 转交=是 目标设备=huangwenlong的 Mac mini
```

## 后端选择

开始操作前，检查当前可用的设备、控制工具和登录状态，并选择能够完成全部必要步骤的后端：

1. 优先选择已连接、可见且能操作支付宝的后端。
2. 后端必须能完成申请、用户认证接管、提交状态确认、生成状态检查、下载和本地保存。
3. 需要转交时，后端还必须支持用户指定的目标设备或渠道；不满足时先报告缺少能力，不执行部分转交。
4. 同一请求只选择一个后端。后端中途失去连接时，先检查当前业务状态，再决定恢复、切换后端或停止；不要盲目重复申请。
5. 选择后加载对应适配文件。适配文件只描述平台入口、控件、认证接管和文件操作，不重复定义业务状态或安全边界。

当前适配文件：

- [iOS + Computer Use](references/ios-computer-use.md)：使用 iPhone 镜像操作支付宝。

未来适配文件示例：

- `references/android-adb.md`：使用 Android + ADB 操作支付宝。

## 业务流程

按以下状态推进 `alipay-bill`，每一步都记录可见证据。状态名称是业务状态，不随后端改变：

1. **未开始**：确认时间范围、保存位置、是否转交和目标设备；确认没有需要补充的关键参数。
2. **后端已选择**：确认所选后端满足当前请求的能力要求，并加载适配文件。
3. **等待用户认证**：进入支付宝认证页面后立即暂停，让用户在设备上完成面容 ID、支付密码或设备认证；不得读取、输入、复述、保存或推测认证信息。用户确认完成后继续。
4. **申请已提交**：确认页面明确显示提交成功；记录申请的时间范围和接收方式。提交成功后不得重复申请。
5. **等待生成**：检查支付宝是否提示异步生成，以及是否需要等待服务消息；保留已提交状态，不创建重复申请。
6. **文件可下载**：确认消息或申请记录对应本次时间范围，并且明确显示文件已生成后再下载。
7. **文件已保存**：确认文件保存成功、保存位置正确，并报告文件名或后端可见的文件标识。
8. **转交已完成**（仅用户授权转交时）：确认目标设备或渠道与用户指定一致，并确认发送成功；等待中、被拒绝或目标不匹配都不能报告为完成。

## 状态检查与恢复

- 页面只显示加载中、返回首页或模糊提示时，不把申请当作成功；继续寻找明确的提交成功、生成完成、下载完成或发送成功证据。
- 发现已有相同时间范围的已提交申请时，优先复用并检查其生成状态，不重复提交。
- 认证被取消、后端断开或页面回退时，先读取当前页面和申请记录，判断仍处于哪个业务状态，再恢复对应步骤。
- 申请已提交但证明尚未生成时，向用户报告等待时间和当前状态；不要通过反复申请“催生”文件。
- 文件下载或保存失败时，可以在不改变申请参数的前提下重试下载；不得重新申请，除非用户明确要求且确认没有可复用申请。
- 任一状态无法可靠确认时，停止并报告“状态未确认”、已知证据和下一步所需的用户操作。

## 安全边界

- 不读取、输入、复述、保存或推测支付宝支付密码、面容 ID 或设备密码。
- 不擅自修改支付宝账号、身份、交易类型、时间范围、接收方式、文件名或保存位置。
- 未获得单独授权时，只保存到用户指定或默认的本地位置，不通过邮件、聊天、云盘或其他渠道发送。
- 转交前再次核对目标设备或渠道；目标不一致、不可见或需要额外授权时暂停。
- 报告申请、生成、下载、保存和转交分别是否完成；不要用其中一个状态代替另一个状态。

## 交付报告

结束时用简短报告说明：

- 使用的后端；
- 时间范围和接收方式；
- 申请是否提交；
- 证明是否生成；
- 文件是否下载并保存，以及保存位置；
- 是否执行转交、目标和结果；
- 未完成项、等待时间或需要用户接管的步骤。
