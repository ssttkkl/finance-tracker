# 支付宝账单流程

本文件完整定义支付宝`交易流水证明`的业务操作，不绑定 iOS、Android、Computer Use 或 ADB。执行前另行加载统一入口选定的设备控制后端。

## 参数映射

- `时间范围`：默认`最近三个月`。可选择`最近一个月`、`最近三个月`、`最近一年`或用户确认的`自定义`范围。
- `交易类型`：默认`全部交易`。
- `接收方式`：固定选择`支付宝`，不得误选邮箱。
- `用途`：选择`用于个人对账`。
- `保存位置`：默认使用后端可控制的设备本地文件根目录。
- `转交`：默认`否`；只有用户明确授权并指定目标设备或渠道时才执行。

## 申请交易流水证明

1. 打开支付宝。
2. 依次进入`我的` > `账单` > 右上角`…` > `开具交易流水证明`。
3. 选择`用于个人对账`，点击`申请`。
4. 进入面容 ID、支付密码或设备认证页面后立即暂停，请用户直接在设备上完成认证并回复。不得代为处理认证信息。
5. 用户回复后恢复设备控制，进入`选择交易流水范围`页面并设置：
   - `交易类型`：使用传入值，默认为`全部交易`；
   - `时间范围`：使用传入值，默认为`最近三个月`；
   - `接收方式`：`支付宝`。
6. 点击`下一步`。
7. 确认页面明确显示`提交成功`，记录时间范围和接收方式，再点击`完成`。不得重复申请。

## 等待文件生成

1. 返回支付宝首页。
2. 在`最近消息`中等待`我的账单`出现`您的交易流水证明已生成`。
3. 打开该消息，点击`查看详情`。
4. 在`申请记录`中选择与本次时间范围匹配的最新记录。
5. 确认记录明确显示文件已经生成，然后点击`下载文件`。

## 下载、保存与转交

1. 在设备的系统保存界面选择用户指定位置；用户未指定时使用设备本地文件根目录和默认文件名。
2. 确认保存界面关闭或出现其他明确保存成功证据。
3. `转交=否`时结束。
4. `转交=是`时，打开已保存文件的系统分享界面，选择用户明确授权的目标设备或渠道。
5. 等待状态变为`已发送`或其他明确成功状态后，才报告转交完成。

## 状态恢复

- 页面只有加载中、返回首页或模糊提示时，不判定为提交成功。
- 误选`邮箱`时返回接收方式，改选`支付宝`后再继续。
- `提交成功`页面没有关闭时点击`完成`或可见返回按钮，不要再次点击`申请`。
- 已有相同时间范围申请时，优先复用最新且匹配的记录，不重复提交。
- 最近消息尚未出现时保留已提交申请；支付宝可能提示最长 24 小时，不反复申请。
- 下载后未出现保存界面时，先确认下载动作是否成功，再重试下载，不要重新申请。
- 转交显示`等待中`时不报告完成；检查目标是否可见并允许接收。
- 目标与用户指定不一致时立即停止，不根据相似名称猜测。
