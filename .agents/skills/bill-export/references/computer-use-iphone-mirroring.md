# Computer Use + iPhone 镜像后端

本文件只定义如何通过 Computer Use 操作 macOS 的`iPhone镜像`界面。应用内业务入口、按钮顺序、参数和状态判断全部以已加载的渠道流程文件为准。

## 能力检查

选择本后端前确认：

- `iPhone镜像`正在运行或可以启动，并且可见、可交互；
- 目标支付应用已安装，用户已登录正确账号；
- Computer Use 可以读取截图、点击、滚动、按键，并能观察页面状态；
- 当前请求涉及本地保存时，iOS 系统文件保存界面可用。

任一必要能力缺失时，返回统一入口选择其他后端或报告缺失能力。

## 初始化

1. 使用 Computer Use 的 `node_repl` + `@oai/sky` 完成所有桌面交互。
2. 目标应用使用包标识 `com.apple.ScreenContinuity`；按显示名操作时使用`iPhone镜像`。
3. 开始前读取一次完整应用状态。需要回到 iPhone 主屏幕时按 `super+1`；需要应用切换器时按 `super+2`。

## 观察与操作

- 每次操作前读取当前状态；每次点击、按键、滚动或导航后重新读取状态，再决定下一步。
- 优先使用辅助功能元素索引。镜像中的 iPhone 内容经常不暴露索引，此时根据最新截图确定点击坐标。
- 页面发生任何变化后不得复用旧坐标。
- 滚动使用 `scroll`，不要用 `drag` 模拟滚动。
- 对加载遮罩、页面滑入、动画和空白内嵌网页，等待并重新读取状态，直到画面稳定。
- 点击无响应时先读取新状态，确认目标仍在原位置后最多重试；不要连续盲点。
- 不使用 AppleScript、Shell 输入模拟或其他桌面控制方式替代 Computer Use。

## 用户认证交接

- 渠道流程进入身份验证状态后，立即停止 Computer Use 操作，请用户在实体 iPhone 上完成认证。
- 不读取、输入、复述、保存或推测支付密码、面容 ID、指纹或设备密码。
- 认证可能使镜像显示`iPhone使用中`或`锁定iPhone以连接`。请用户完成后锁定 iPhone 并回复。
- 用户回复后重新读取镜像状态；出现`连接`按钮时点击，等待画面稳定，再按渠道流程确认业务状态。

## 通用文件保存

- 渠道流程要求保存到 iOS“文件”时，在系统分享界面选择`保存到“文件”`。
- 用户未指定位置时使用`我的 iPhone`根目录，并保留默认文件名。
- 点击右上角`保存`后重新读取状态；只有文件选择器已关闭或出现其他明确成功证据时，才视为保存完成。
- 渠道流程要求转交时，只在用户明确授权后操作系统分享界面，并核对目标名称与最终发送状态。

## 断线恢复

- 非认证环节断线时，先尝试重新读取状态并点击`连接`。
- 无法自动恢复时，请用户锁定 iPhone，再重新连接。
- 恢复后先观察当前应用页面，并交由渠道流程判断业务状态；不要自动重启应用或重新申请账单。
