# 账户模块

[返回产品总览](../feature-map.md) · [跨端覆盖与待办](../feature-map.md#跨端覆盖与待办)

本模块当前 **没有独立账户管理页面**。账户能力嵌入其他任务，不另计页面级功能。

## 现有入口与业务路径

| 入口 | 账户相关路径 |
|---|---|
| F-04 收支详情与记账 | 记账时选择收支账户 |
| F-05 现金账单导入 | 选择来源对应账户，必要时新建账户或补齐币种；退出时按提示保留或撤销本次账户变更 |
| F-08 投资持仓 | 按投资账户筛选持仓 |
| F-09 投资流水 | 按投资账户筛选事件 |

账户新建、币种补齐与取消恢复的具体路径和验证缺口见 [导入模块](import.md)。账户别名、生命周期、多币种和分币种余额以 [账户规格](../../openspec/specs/accounts/multi-currency-accounts/spec.md) 为准，不据后端能力认定存在独立客户端管理入口。
