# 账户模块

`ft account` 提供记账和导入所需的账户清单、币种与分币种余额。单独生效的导入账户改动可按原批次查看和撤回，入口见[账本 CLI](../../compose/README.md#账本-cli)。


[返回产品总览](../feature-map.md) · [跨端覆盖与待办](../feature-map.md#跨端覆盖与待办)

本模块当前 **没有独立账户管理页面**。账户能力嵌入其他任务，不另计页面级功能。

离线时可选择缓存中的账户并继续本地核对；创建、修改、补齐币种和撤回账户修改须有在线资格。所选账户已有全部币种时不产生账户写入。在线已冻结的原撤回操作保留原键，恢复联网不自动发送。

## 现有入口与业务路径

| 入口 | 账户相关路径 |
|---|---|
| F-04 收支详情与记账 | 记账时选择收支账户 |
| F-05 现金账单导入 | 选择来源对应账户，必要时新建账户或补齐币种；退出时按提示保留或撤销本次账户变更 |
| F-08 投资持仓 | 按投资账户筛选持仓 |
| F-09 投资流水 | 按投资账户筛选事件 |

账户新建、币种补齐与取消恢复的具体路径和验证缺口见 [导入模块](../import/feature-map.md)。账户别名、生命周期、多币种和分币种余额以 [账户规格](../../openspec/specs/accounts/multi-currency-accounts/spec.md) 为准，不据后端能力认定存在独立客户端管理入口。

账户命令与别名写入已维护服务端账本版本，同一事务仅推进一次，收据重放和拒绝操作不推进。账户准备 HTTP 操作已支持原工作区预期守卫，内部客户端可固定原凭据及请求正文，并沿原键或 ID 核实永久账户收据；本地生命周期仓储与 Graph 尚未消费该入口，现有导入账户路径仍保留；验证范围见 [离线账本任务](../../openspec/changes/offline-first-ledger-import/tasks.md)。
